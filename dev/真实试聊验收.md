# 真实试聊验收工具

本工具是 2026-10-29 用户授权的单独验收批次：`dsv4.1f`、最多二美元。只在服务器使用，默认列计划不读 Key、不调用模型；自动回归仍使用 mock。

- `chat-test-real-acceptance.mjs`：隔离 Fastify、真实 ChatTestService、正式人设预设、Pi 模型适配器及独立统一计量。
- `chat-test-real-cases.json`：中文操作和预期。一个试聊会话模拟一个用户；公开保留各自平台线程，不跨线程合并。
- `real-chat-budget.mjs`：逐请求持久预留与峰价结算，未知保留、原子落盘、全局停止；不修改应用源码或生产配置。
- `real-chat-budget-selfcheck.mjs`：无需 Key 和网络的十一组预算故障自检。
- `real-chat-integrity.py`：生产只读散列快照；健康任务和告警自然刷新须另行归因，不能掩盖变化。
- `real-chat-assess.py`：只读本批既有结果，保存独立复核，不覆写初轮失败，不产生模型请求。

执行前须取得本批明确授权，冻结现有模型和真实峰价来源，并准备独立私有目录；不得以此批授权发起其他模型、生产平台或新预算。实际运行使用全程 `flock`，容器只挂本批目录、候选代码和单一临时凭据，不挂生产数据，串行执行。

`--execute` 和 `ALLOW_REAL_CHAT_USD=2` 同时设置后才付费；已有结果不允许隐式重跑。`--followup-presets` 仅针对本批三个被同文过滤的角色使用独特措辞补测，沿用同一个预算账本和二十四次总上限，另存 followup 文件。当前批次已结束、临时 Key 已删除，不能照抄命令重复付费。

完整执行、费用、原始失败和审阅边界见 [本批记录](../docs/实施记录/2026-10-29-dsv4.1f真实试聊.md)。真实效果须由管理员审阅后确认，工具不自动勾选 OpenSpec 任务。
