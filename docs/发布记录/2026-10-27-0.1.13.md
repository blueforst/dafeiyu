## 改动

原先只检查供应商级 Base URL，并固定排除部分供应商，导致 OpenCode Zen、OpenCode Go、Radius 和 Copilot 没有列出。本次使用供应商或模型级地址，完整列出 pi 1.4.0 的 42 个内置服务商，再增加 Command Code 预设，共 43 项，其中 36 项可选择。其余 7 项展示尚未接入的具体原因，包括云参数、OAuth 或没有聊天模型。

- 补齐 OpenCode Zen/Go、Radius、Copilot API Token 方式。
- Command Code 使用 2026-10-27 官方 Provider API 返回的 94 个聊天模型；Claude 使用 Messages，其余使用官方支持的兼容接口，添加 Bearer 认证。
- 按模型选择协议及地址；保留手工修改地址，防止切换模型导致 `/v1` 重复或请求落到错误协议。
- OpenCode/Command Code 从 `/v1/models` 拉取目录，Radius 使用原生 `/v1/config`。
- Command Code 未提供的价格显示“未提供”，不套用原厂价格或显示为免费。
