# 人设、日程与正常流程试聊

本说明对应已发布的 0.1.19，生产验收见[发布记录](发布记录/2026-10-29-0.1.19.md)。人设页采用铺满视口的工作区，左上角切换人设、日程、试聊三种模式；侧栏可收起，窄屏使用抽屉和详情浮层。

## 人设库

“我的人设”可保存最多二十项，每项有独立名称、修订号和来源。恰好一项处于“使用中”，生产回复、早晚安帖与日程生成都读取它。其他人设的编辑与保存不会切换生产人设。

可以从空白开始、从六个内置预设新建，或复制已有人设。内置预设为只读模板；“以此新建”只创建新项，不覆盖当前内容。编辑页按始终生效和被问到才用分组，保留分区内容、关键词与语义触发卡、顺序、启用状态及固定规则。

保存需带该项修订号，出现冲突时保留编辑，请重新读取并合并。名称去除首尾空白后需一至四十字、库内唯一。保存使用中的项从下一轮生效，不恢复暂停的业务。

“⋯”菜单提供设为使用中、复制、重命名和删除。启用需要确认，使用中的项不能删除。切换不会自动改变已经生成的今日日程，需要时可手动重新生成并计费。角色预设及其派生人设显示建议简介，可一键复制；启用后提醒管理员在恢复业务前修改 X 名称和简介，并考虑在合规披露词中加入“非官方”。程序不自动修改账号资料。

人设库未保存过时只读提供“当前人设”，内容与升级前生效人格一致。首次库写入才落盘，`persona` 兼容镜像始终保持使用中内容。回退版本读取该镜像，当前生产人格不变。

“动态提醒”是库中独立的全局条目，所有人设共用同一份迟到、语言、表情和生成前自检设置，保存后从下一轮生效。

## 回放比较

在人设页头打开“回放对比”。候选为该项的编辑草稿，已保存基线取同一项保存版，历史实际回复基线仍按原规则取样。先预估费用，再确认开始；私信样本需额外允许。采用候选保存回发起回放的人设，不切换使用中项；发起后该项修订变化时拒绝覆盖。历史回放保留人设名称，已删除的人设仍可检查记录。

## 日程模式

左栏列出近七天，标注已生成、已编辑或失败无日程。主区按选中日期显示时间线、三餐、活动、心情、来源、更新时间、修订、人设与关联费用；旧记录未保存生成人设时显示“未记录”。仅今天高亮当前时段并提供编辑和重新生成，过去日期只读。

日程在北京时间下运行。生成计划只有设置页“定时任务”一份，人设页齿轮链接到该位置；内容编辑不新增第二份计划。没有日程时显示缺失状态，不沿用前一天。

## 正常流程试聊

左栏一个会话代表一个模拟用户。同一会话里连续消息保留该用户的长期记忆、近期往来、冷却与整理进度；新建会话创建独立的模拟用户。显示名和测试 handle 可改，支持重置、清除冷却和删除。每个模拟用户的公开与私信仍是两个身份，记忆与冷却互不相通。

输入框只选择已保存人设，默认使用中项。处理开始时固定本轮人设版本，处理中保存或切换不会改变本轮。编辑器尚未保存的修改不会进入试聊。

试聊共用正常生成流程，包含分级、广告过滤、骚扰冷却、记忆召回、当天日程、人设和触发卡、动态提醒、模型跳过、字数校验及格式标记。通过校验的回复在测试库中视为已发出，下一轮能召回；超长回复显示“正常流程不会发出”，不算已发出。按生产阈值自动整理测试记忆，也可在记忆标签手动整理。

“先攒几条再回”开启时消息只入队。私信处理时只把最后一条作为本轮，前几条作为会话上文。公开消息每条保留独立的平台线程 ID，不跨线程合并；它们仍属于同一个模拟用户，继续共享公开身份的记忆与近期往来。点击“让角色回复”处理等待中的条目。

试聊不发到 X，不访问浏览器，不占小时、每日、每轮额度，不受回复时段、排队时效、暂停、接管、自动／草稿模式、退避或 unknown 出站限制。它不改变业务控制状态。

点击一轮后右栏可切换本轮详情、记忆、提示词。详情包括所用人设、分级、命中、提醒、模型调用、token、费用、耗时和校验；记忆按公开与私信身份分别展示；提示词按实际请求顺序区分稳定前缀与动态内容。无价格或用量证据时显示未定价或未知，不视为免费。

同一模拟用户同时只处理一轮，整个面板最多两轮。处理中可取消，失败或取消的消息回到待处理，可重试；已落账费用保留，重试再次计费。取消与重置会阻止旧请求回写。

## 数据隔离与计费

测试数据放在 `DATA_DIR/chat-test/`，拥有独立 SQLite、遗忘账本和记忆变更账本。测试用户不会出现在生产动态、记忆管理、额度、健康、日报、回放样本、质量统计或业务数据库备份中。生产的人设、模型、提醒、分级、当天日程、角色经历与字数能力只读使用。

唯一写入生产库的是统一模型调用流水，用途为“试聊”（`chat-test`），来源区分回复、语义判断和记忆整理。页头累计费用与计费流水同口径。账号未确认时日程、经历与账号近期回复为空，字数按普通规则，页面明确提示。

旧 `POST /api/persona/preview` 接口仅供批量验收工具使用，保留原模拟参数与行为；面板不再提供模拟记忆、模拟日程的旧试聊表单。

## 地址和编辑保护

- `#/persona`：使用中人设。
- `#/persona/p/<id>`、`#/persona/p/<id>/replay`：人设配置与回放。
- `#/persona/preset/<id>`、`#/persona/hints`：只读预设与全局提醒。
- `#/persona/daily/<日期>`：指定日期日程。
- `#/persona/chat/<会话 id>`：模拟用户的试聊会话。

旧 `#/persona/persona`、`#/persona/daily`、`#/persona/preview` 分别打开对应模式。模式切换保留最近选择的条目。切换条目、模式和页面时有未保存修改会询问“保留编辑”或“放弃并离开”；刷新和关闭浏览器同样保护。
