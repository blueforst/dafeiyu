# 七页面板

面板使用原生 ES 模块，默认地址 `#/overview`。一级入口恰好七个：主页面、模型、人设、记忆、主程序、定时任务、计费。各页可通过对应 hash 地址直接打开。

主页面包含运行、账号、模型，以及按需展开的浏览器接管区。日志集中移入主程序页，沿用原主页面的时间／事件／说明行式展示，替换原主程序日志列表，并保留筛选和暂停实时能力。旧地址 `#/browser` 自动转到主页面并展开接管区；展开本身不会连接桌面，仍需点击“接管并连接”。释放人工接管后桌面连接关闭，业务保持暂停。

人设页提供静态分区、按顺序生效的语义触发卡片、固定系统约束和多轮试聊。试聊使用当前未保存稿、公开或私信模拟场景，以及单独填写的模拟记忆；展示回复或跳过、命中原因、实际提示词分段、耗时和统一调用费用。虚构日程在本页查看、编辑或重新生成，生成计划只在任务页修改。

记忆页按工作账号、渠道和用户／会话检索，展示近期原文、长期条目、来源、整理进度和遗忘状态。来源不完整的旧摘要明确标记。条目保存与删除携带修订号；只读召回入口不写回记忆。重新整理会请求模型，遗忘会删除对应内容并停止后续记录，“恢复后续记录”不会恢复已经删除的数据。

主程序页将全局控制和处理阶段分别展示，可查看轮次、耗时、关联消息、队列、通道额度与退避。运行设置修改模式、时效、每轮数量和额度，轮询间隔统一在任务页维护。消息正文仅在管理鉴权后的详情入口按需读取；日志支持级别、渠道、北京时间范围和关联 ID 筛选，并可暂停实时刷新。

任务页区分保存计划和单次执行，展示上次与下次执行、有限分页历史、错误、平台回执和原模型调用。主循环启停对应全局运行控制，其他计划保存不会恢复业务。早晚安和备份初始关闭；宿主健康检查保持独立。未安装维护桥接时页面明确说明状态，不将应用内状态冒充宿主检测。

计费页提供今日、本月和自选日期范围。界面结束日期包含当天，接口转换为北京时间的半开范围。汇总、趋势和流水采用相同筛选口径，完整展示输入、输出、缓存读取与写入；思考属于输出子集。费用使用 Pi 调用时快照，未定价和用量未知单独展示，不把未知消费写成零。

所有新视图使用纯文本 DOM 构建，支持系统浅色／深色和 375px 宽度。配置编辑提供未保存离页保护，保存失败保留当前编辑；修订冲突由接口明确返回，不自动覆盖其他版本。

## 验证

`test/seven-pages-acceptance.mjs` 在服务器的 Camoufox 镜像内运行。默认先读取实际 staging 的十二组接口，再用模拟接口验证七页浅／深色和桌面／375px 布局、旧浏览器入口、未保存离页、多轮试聊隔离、记忆来源警告与只读召回、暂停状态下计划保存、未定价展示以及加载后的空／错误状态。日程保存期间禁用编辑、重复打开保留稿，以及试聊返回不清除下一轮输入均有专门回归。输出到 `/artifacts/seven-pages-acceptance.json` 和对应页面 PNG。

只有确认地址是独立 staging 且配置为模拟模型时，才可启用 `PANEL_STAGING_MUTATIONS=1`，验证实际接口的同值配置保存、旧修订冲突、只读召回和保存后仍暂停；`PANEL_STAGING_PREVIEW=1` 另验证模拟模型试聊与统一计费流水的关联。禁止将这两个测试开关用于生产地址。

模拟页面验证与真实接口、真实模型、X 实际采集和发送回执分开记录。本脚本不使用生产账号，也不构成真实平台验收。
