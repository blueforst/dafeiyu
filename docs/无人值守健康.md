# 无人值守健康实现说明

本次增加运行预算、看门狗、浏览器资源观察与恢复、持久告警、北京时间日报和只读账号检查。实现代码与隔离测试不代表生产发布，当前账号的真实页面与长期运行证据需要另行验证。

## 数据与接口

`RuntimeHealth` 的第 10 条加法迁移创建 `alerts` 和 `daily_reports`，按账号隔离。告警活动唯一键为账号与指标；持续问题更新最后发现时间，恢复后写入恢复时间。日报按日期、账号唯一，不含消息、私信、简介或模型提示词原文。

受现有管理鉴权保护的只读接口：

- `GET /api/health/settings`：读取有效健康配置与该域修订；`PUT /api/health/settings` 保存平铺配置字段与必需的 `revision`，过期返回 409，保存不改变控制模式。
- `GET /api/health`：上一次评估结果、活动告警、浏览器资源摘要与合规摘要。不导航浏览器，不调用模型。
- `GET /api/health/alerts?cursor=&limit=`：当前工作账号的告警历史，默认 30、最多 100 条。
- `GET /api/health/reports?limit=`：当前工作账号最近最多三十份日报。
- `GET /api/health/reports/:date`：指定北京日期的日报。

所有 GET 和 SSE 读取缓存。评估由工作轮次结束与独立看门狗周期驱动。宿主监控独立请求状态与健康；失败时保留旧健康快照的原获取时间并标过期，容器和证书检查继续运行。

## 运行与恢复

默认软超时八分钟、硬超时十二分钟。软超时只阻止开始下一条消息，硬超时中止原控制器；已保存提交意图的出站仍必须进入 unknown 回查。公开与私信各九十秒采集预算，正常返回已采集消息与警告。RPC 默认一百二十秒并接收轮次中止信号。

看门狗只读内存状态、恢复唯一调度器或请求中止，不访问浏览器。卡住阈值为硬超时加两分钟；两次恢复失败后安全暂停。请求恢复后至少等待三十秒，不另起并发轮次。

浏览器内存优先读取 cgroup v2，失败时只读 `/proc` 统计 Camoufox 进程树 RSS，采用与当前 Compose 对应的 2 GiB 上限；都无法读取时显示未知。默认达到内存上限 75% 或运行二十四小时后，在下一项读取操作前关闭并重建持久上下文，重新核对原账号。send、post、lookup、lookupPost 及人工接管／排空期间禁止资源重启。重启失败或身份变化保持暂停。提交日志和独立的未提交预检日志均不因恢复而删除。

浏览器串行请求超时会暂停并关闭当前页面，使待完成操作退出；请求先返回超时，但串行队列仍等待旧操作退出并恢复页面后才接下一项，避免旧操作与新页面并发。未能退出时由工作流看门狗安全暂停，不能用重新发送绕过。

## 日报与账号检查

`daily-report` 默认每天 09:00 启用，汇总前一北京自然日。日报不使用浏览器或模型，即使全天暂停仍生成，晚启动时补同一天一次。收到按消息平台时间统计，处理结果按其最后状态更新时间统计；响应中位数与 P90 只使用可靠入站时间。缓存读取占比为 cacheRead/(input+cacheRead)，未定价与未知用量单独保留，费用标注 Pi 目录估算。

`account-check` 默认 10:00 启用，自动运行要求工作流运行且浏览器空闲。暂停期间只有管理员明确立即执行才读取，完成后继续暂停，人工接管不执行。检查只导航到自己的资料页、通知设置及页面实际提供的过滤链接，不点击发送、资料编辑或任何开关。结果只保存披露是否完整、缺少的配置词、自动化标签状态和质量过滤状态；无法可靠解析时明确显示无法确认。

披露词默认 `AI`，在 `health.requiredPhrases` 设置中按全部词、忽略大小写匹配名字与简介。未标注自动化标签或质量过滤开启只产生注意提示，不自动改账号。明确受限提示则安全暂停；匹配自身账号提示前移除帖文、私信和资料正文，降低引用文本造成的误判。

## 验证边界

`test/unattended-health.test.ts` 包含可控时钟、持久告警、日志边界、暂停日报、资源恢复门禁及串行超时测试；`test/health-monitor.test.ts` 覆盖宿主不可达与旧快照。全部构建和自动化测试应在服务器独立环境执行。

受限文本测试是明确标记的合成契约夹具，没有声称取得真实冻结、只读或自动化拦截页面。只读资料与通知设置解析仍需真实页面留证，无法确认的类型继续未知；不能为采样而主动制造受限状态。资源重启需要独立 profile 的浏览器验收；不得在生产 profile 上注入高内存或受限样本。

新表属于普通数据库备份范围。回退时暂停、保留告警日报与浏览器日志，旧版本可忽略加法表；不删除 unknown 出站、不清理未对账预检记录。没有新增宿主任务白名单，没有外部邮件或 Webhook 推送。
