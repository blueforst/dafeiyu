# 浏览器环境排查记录

当前部署说明：0.1.7 强制启用完整 SwiftShader 后，用户反馈接管卡顿，浏览器 CPU 实测约 196%，接近占满双核。0.1.8 已撤回该图形驱动设置，恢复默认图形路径；线程容量修复继续保留。下面的 0.1.7 内容是历史诊断过程，不应当作当前推荐配置。

本记录对应 2026 年 10 月 27 日的服务器环境检查。账号、代理出口和会话重置分别记录，不能把环境修复当作登录验收通过。

## 已确认的问题

1. 浏览器容器原先的进程与线程总量上限为 384。保留业务浏览器与人工对照浏览器后，出现了 31 次上限事件，日志包含 `pthread_create: Resource temporarily unavailable`。同期没有内存触顶或 OOM。上限已在线提高到 768，并同步到 Compose；内存上限仍为 2 GiB。
2. 人工 Chromium 的 WebGL 1/2 均不可用。`chrome://gpu` 提示 GPU 启动失败及功能禁用。提高线程额度并重启后，WebGL 仍不可用，说明图形问题还需单独处理。
3. 实际能力检查中，人工窗口 `navigator.webdriver` 为 false，Canvas2D、WebAssembly 和 Worker 正常。现有证据不能将拒绝登录简单归因于这个自动化标志。

## 图形对照与修复

在隔离的 Xvfb 显示中，仅加载自建离线检查页，逐一测试默认后端、Mesa 软件 OpenGL 和 SwiftShader 图形驱动。前两项的 WebGL 不可用；SwiftShader 驱动可以创建 WebGL 1/2。

浏览器镜像 0.1.7 对业务浏览器及人工窗口统一使用以下驱动参数：

```text
--use-gl=angle --use-angle=swiftshader
```

上述参数已在 0.1.8 中移除。功能可用并不代表适合持续交互；本次改动未解除 X 登录限制，并引入性能回退。

业务浏览器同时移除 Playwright 默认的 SwiftShader WebGL 回退参数，使用同一套完整图形驱动路径。浏览器继续采用非 root 用户与 Chromium 沙箱。实际渲染器如实报告为 SwiftShader，不修改其标识。

生产人工窗口还验证了 WebGL 清屏与像素读回，检查结果包括渲染器名称、RGBA 数值和 GL 错误码。离线脚本位于 `test/browser-environment.html`，只检查能力，不读取账号、Cookie 或密码，也不发出外部网络请求。

## 验收资料

服务器 `/var/lib/role-workflow/acceptance` 保存：

- `浏览器线程容量修复.json`：调整前的计数、额度和配置备份位置。
- `浏览器图形报告-修复线程前.txt`：Chromium 原始图形报告。
- `浏览器能力检查-修复线程后.json`：修复线程后、调整图形驱动前的能力结果。
- `浏览器离线图形对照.json`：三个图形后端的对照结果。
- `浏览器能力检查-图形修复后.json`：生产人工窗口的实际结果。
- `浏览器图形修复构建.log`：服务器构建及 14 项回归检查记录。
- `X公共登录页资源检查.json`：隔离浏览器打开公共登录页的加载情况，没有提交账号或密码。

公共登录页检查不能覆盖输入账号后才发生的验证请求。登录是否成功仍需单独记录，不自动开启业务处理。

随后在生产人工窗口中，以固定代理和修复后的浏览器复现了一次用户名提交。`POST https://jf.x.com/onboarding/web/actions/begin_login` 返回 HTTP 200，但响应正文的 `begin_login errors` 和 `username_or_email` 字段直接包含临时登录限制提示。请求耗时约 708 毫秒。该观察已记录到 `X登录拒绝响应取证.json`，没有导出 HAR、Cookie 或认证请求头。

这将故障定位到 X 登录接口的应用层拒绝，尚不能从可见错误判断具体风险触发条件。线程和图形问题的修复没有解除登录限制，不应将本次环境验收写成真实登录验收通过。

## 回滚

保持业务暂停。恢复 `/var/lib/role-workflow/releases/env-before-browser-0.1.7` 到服务器 `.env`，再重建浏览器，即可退回上一镜像。回滚不删除浏览器资料与数据库。

线程额度可独立保留为 768。若需要恢复到 384，应先退出多余浏览器实例，避免再次碰到线程上限。

图形后端的官方说明见 [Chromium SwiftShader 文档](https://chromium.googlesource.com/chromium/src/+/main/docs/gpu/swiftshader.md)。
