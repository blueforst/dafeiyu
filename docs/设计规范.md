# 面板工作区设计规范

## 版式

工作区在全局顶栏下铺满视口，不使用旧卡片页的最大宽度与外边距。左栏提供当前页面的列表，主区负责编辑或阅读；只有需要检查单条记录详情时才显示右栏。三栏页头高度统一为 44px，页头只放当前模式、条目名称与操作。各栏内容独立滚动，试聊输入框固定在主区底部。

桌面左栏默认 232px，详情栏默认 300px；较窄桌面分别为 208px、270px。主区始终可收缩。宽度不超过 860px 时左栏为默认关闭的抽屉，右栏为浮层；打开浮层后焦点进入，Tab 保持在浮层，Esc 或遮罩关闭后恢复触发元素焦点。375px 下表单单列、主要操作始终可见，不允许整页横向滚动。

左、右栏的收起状态分别存在 `ws:<page>:left`、`ws:<page>:right`，值 `1` 表示收起。所有存储访问都有异常保护；禁止存储时桌面默认展开，当前页面仍可收起。移动端默认关闭不覆盖桌面偏好。

| `--ws-active` | `#ebeef2` | `#2c2c2e` | 选中与分段控件背景 |
| `--ws-card` | `#f5f7fa` | `#1f1f21` | 内容卡片 |

| `--ws-border` | 黑色 8% | 白色 8% | 细边界 |

圆角采用 `DESIGN.md` 定义的阶梯令牌：`--r-xs`（4px，微角标）、`--r-sm`（6px，徽标、紧凑轻按钮、分段与菜单内嵌项）、`--r-md`（8px，标准按钮、输入框、列表项、分段外框）、`--r-lg`（10px，二级卡片、表格框、弹出菜单与通知）、`--r-xl`（12px，一级卡片）和 `--r-2xl`（16px，模态弹窗、对话气泡与复合输入盒），嵌套组件遵循内外同心定律（$R_{\text{outer}} = R_{\text{inner}} + \text{Padding}$）。四级文字大小为页头 13px、正文 14px、说明 12px、注释 11px。

## 组件与接口

`public/js/shell.js` 导出 `mountWorkspace(root,{page,left?,main?,right?})`。`right` 省略时使用两栏；传 `true` 可建立三栏。返回：

- `left`、`main`、`right`：可滚动的内容容器。
- `leftHeader`、`mainHeader`、`rightHeader`：页头内容槽，可整体替换；通用栏收起按钮独立存在，不受替换影响。
- `leftPane`、`mainPane`、`rightPane`：含页头和内容的完整栏；固定输入框放在 `mainPane` 末尾。
- `setRight(visible)`、`collapse(side,bool)`、`open(side,trigger?)`、`close(side)`、`isCollapsed(side)`：调整详情可用性和收起状态。
- `dispose()`：清理监听、恢复旧页面 `main` 布局并卸载工作区。调用页面必须在卸载时执行。

共享组件包括：

| 导出 | 参数与职责 |
| --- | --- |
| `sideItem` | `{title,subtitle,meta,selected,badge,icon,onclick,href,...attrs}`；左栏条目，选中项带 `aria-current` |
| `segmented` | `([[值,名称],...],当前值,onChange,无障碍名称)`；分段模式切换 |
| `badge`、`chip` | `(text,kind)`；`kind` 为 `ok`、`warn`、`bad`、`blue` |
| `button` | `(text,onclick,{primary,...attrs})`；主按钮和普通操作 |
| `card` | `(title,...children)`；内容卡片 |
| `input` | `(attrs)`；单行输入框 |
| `composer` | `{input,controls,footer,onsubmit}`；固定在主区下方的输入区域 |
| `turn` | `{role,text,summary,footer,kind,selected,onclick,children,interactive,...attrs}`；`role` 为用户、角色、说明或系统提示，`interactive` 标记可键盘选择的轮次 |
| `stateMessage` | `(text,{error,retry})`；加载、空状态和失败重试 |
| `advanced`、`advancedDialog` | 底部可记住折叠的高级设置块（`ws:adv:<key>`）与页头弹窗式高级设置 |
| `fmtUsd`、`rowActions`、`emptyLine`、`tagInput` | 两位有效数字美元格式化（悬停精确值）、行内悬停／聚焦操作组、单行静音空状态与药丸标签输入 |

外部文字均通过 `h()` 创建文本节点，不使用 `innerHTML`。输入框与主要按钮必须提供标签；收起按钮提供 `aria-controls`、`aria-expanded` 和可读名称。

## 状态和编辑保护

列表加载、空内容、读取失败分别显示明确说明。失败必须提供重试，不能留旧数据冒充新结果。成功用绿，待处理与未保存用告警色，失败用错误色；状态始终同时有文字，不仅用颜色。

编辑人设、动态提醒、日程和试聊输入时，切换条目、模式、顶层页面均先检查未保存内容。页面内提供“保留编辑”和“放弃并离开”，刷新和关闭浏览器由 `beforeunload` 保护。人设配置与同人设回放视图之间保留同一份草稿；试聊只使用已保存版本，并明确提示。

## 主区二级列表

模型服务商和记忆身份可在主区内部使用二级列表，不占用外壳右栏。宽屏使用列表加详情，窄屏收为顶部选择器；列表与详情均须 `min-width:0`。设置页的 `.settings-secondary-layout`、`.settings-secondary-list` 和 `.settings-secondary-mobile` 遵循此规则。

## 左栏条目与状态圆点

工作区链接条目以 `.ws-shell .ws-side-item` 统一正文色，悬停无链接下划线；选中项沿用背景区分，不改变名称颜色。设置左栏移除文字摘要，仅在配置错误、模型未配置、接管或需要登录、健康需关注或异常、最近任务失败时显示圆点。圆点为七像素，告警与错误分别用现有颜色变量，同时带 `role=img`、可读名称及 title；正常无点。侧栏仅查询健康与最近任务两类摘要，当前子页仍按需加载自己的内容。

健康指标按运行、采集、发送、浏览器、账号、基础设施分组，未知标识归其他；非正常行优先并完整显示说明，正常行宽屏可并排。账号检查只在账号组出现一次。日报表格直接列数值，窄屏仅表格容器横向滚动；告警历史及配置默认收起。

## 对话流、输入框与成对信息

试聊和动态共用 `shell.js` 的 `avatar`、`divider`、`timeDivider`、`reply`、`detailRow` 与 `autoGrow`。`turn`、`composer` 及未传 `iconSeed` 的 `sideItem` 保留原输出；试聊会话传入稳定的用户标识启用新头像。头像用六组 `--ws-avatar-N-bg/fg` 配色，浅深主题逐组保证对比度至少4.5:1；名称取首个完整字素，空名称为“?”。本轮管理员取消生成图片头像，产品仅使用首字头像。

`.ws-thread` 最大680px，对方只有右侧气泡；首条、相隔至少五分钟或跨日时用 `.ws-divider` 标记时间，试聊切换渠道时合并为带横线的渠道分隔。角色使用 `.ws-reply` 的头像、名称、正文、结果提示与操作行，选中只加 `--ws-hover` 灰底。`.ws-stat` 默认透明，悬停、键盘聚焦或选中显示，`hover:none` 下仅选中显示；减少动态效果时关闭过渡和处理中圆点动画。

试聊的 `form.chat-dock` 在主区底部，内部 `.ws-box` 使用 `--ws-fill`（浅色#f3f4f6，深色#232326）和 `--r-2xl`（16px）圆角；控件在 `.ws-box-bar`，说明在 `.chat-caption`。消息输入自动增高到220px，无拖拽角。`#chat-test-channel` 是公开／私信单选组；发送与停止共享位置，待处理操作显示条数。动态草稿复用圆角框，批准说明、重写和发送都在框内；刷新复用原textarea以保护文字、焦点和光标。

右栏 `.ws-detail-row` 使用两列网格，名称不换行，数值可在自身列内任意换行，两列首行顶端对齐。样式和新组件只作用于迁移后的对话流及详情；日程、设置与旧组件不改变布局。

## 人设目录编辑器（2026-10-29 实施，待视觉确认与发布）

我的人设和内置预设的主区采用“目录＋单项编辑”。桌面目录宽 300px，861–1100px 时为 260px；不超过 860px 时使用按“始终生效／触发卡／只读”分组的原生下拉框。目录显示名称、字数、两行预览及按项未保存圆点，不显示占比条。条目之间直接切换，选中项与草稿一起保留；切换人设或离开页面仍有未保存保护。

正文输入框和触发卡内容框填满剩余高度，文本超出时内部滚动并保留纵向拉伸。触发条件随输入增高至八行。卡片提供独立启用开关、添加、指针／触屏拖动，以及可用键盘操作的上下移动与删除菜单。固定规则、建议简介和全部预设字段采用可选中、可聚焦、无边框的灰底文本区，并显示只读标识。复制简介成功后原位提示，失败后选中文本；离开后旧异步结果不能影响新页。

人设列表同模式切换不清空、不替换已有导航节点，保留滚动与焦点；稳定菜单的回调指向当前控制器，操作后关闭菜单。日程、试聊、提醒和回放的布局沿用原实现。

## 调用流水表格（2026-10-29 实施，待发布）

调用流水保持默认收起、按需请求，展开后为七列紧凑表格：时间、状态、模型、账号／用途、耗时、Token、费用。模型的次级行显示接口名；账号采用接口已有账号 ID，状态采用真实调用生命周期，不推造邮箱或 HTTP 状态。缺失值为“—”，未定价单独标示；费用和 Token 摘要可查看精确值。

点击记录或按回车、空格原位展开明细，再次激活收起。明细包括请求及实际模型、调用 ID、来源、渠道、关联、时间、输入输出与缓存计量。记录展开不额外发起请求；分页保留已有记录。窄屏由表格自身横向滚动。范围请求令牌同时隔离成功和失败响应，旧范围不会覆盖新筛选。
