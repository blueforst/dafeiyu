# 账号发帖限制与预检记录

本次实现将原创帖子与公开回复的字数校验集中到 `src/posting-policy.ts`。普通账号、未知、过期、证据冲突及未完成计数验收的情况使用 280 加权字符；普通汉字 140 个通过，141 个停止提交。私信保持 4,000 个 JavaScript 字符。公开正文在冻结前采用 NFC，独立资源保护为最多 25,000 个 Unicode 码点；资源保护上限不代表平台权限，模型输出仍沿用既有设置。

## 当前平台证据边界

没有取得可绑定当前账号的真实长帖权限响应、原生编辑器计数与完整长帖回执样本，因此本版本的长帖计数适配器注册表为空。蓝标、订阅名称、自报上限、历史成功和仅有字段名的响应都不能授权长帖。浏览器返回当前账号与会话绑定的未知状态；公开生成、试聊、持久出站及真正提交使用同一保守策略。

已有普通 `legacy.full_text` 响应保留作者、目标、唯一 ID 与提交时间严格校验。明确 `truncated` 或包含未经真实样本验收的 `note_tweet` 结构时标记正文不完整，不将前缀相同当作确认。完整长帖字段与计数规则的真实平台验收仍未完成，不得据此勾选 OpenSpec 的平台证据或长帖发送任务。

## 接口

- `GET /api/account/posting-limits`：只读本地缓存，不访问 X 页面、模型或浏览器；返回账号、原创／回复能力及生效策略。
- `POST /api/account/posting-limits/refresh`：沿用应用和浏览器串行互斥，只读取现有页面身份与已经验收的能力证据，不导航、不点击发送、不恢复暂停。人工接管、排空或当前业务操作期间返回 409。请求中的自报权限或上限没有授权作用。
- 浏览器内部 `POST /capabilities`：返回浏览器自行绑定当前账号及独立会话的能力摘要；人工接管期间拒绝。进程重启、账号变化和人工释放后旧证据不能授权长帖，缓存有效期最多十五分钟。显式重新读取在到期、人工释放或同 handle 身份 ID 变化后生成新的未知证据和检查修订；不会一直展示旧到期时间。账号、操作、会话、时效或同修订证据冲突会使旧缓存失效。

以上接口沿用入口鉴权和控制请求标记；Key、Cookie、原始响应与认证信息不进入缓存或业务日志。能力读取不会改变现有小时／每日发送额度。

## 未提交终态

浏览器在保存提交意图之前独立校验正文和当前账号的策略；长度错误或编辑器无法提交时，在 `browser/posting-preflight-v1.json` 中持久保存版本 1 的 `not_submitted` 终态，再返回结果。记录只有出站标识、账号、类型、目标、正文散列、时间及校验元数据，不复制正文。

写文件、同步和重命名失败时不能报告已确认未提交，应用继续按未知收束。同进程将失败出站标识及原参数冻结为未知，后续同标识不能重新进入提交；若文件已重命名但目录同步失败，重启后可以从实际持久文件回查终态。同一个出站标识的终态不会自动重发；丢失响应后可以用原标识与冻结参数回查。未对账预检记录不按数量清理。存在原提交意图的出站优先走旧回执路径，不能在订阅降级后重新分类为安全未提交。

应用收到 `not_submitted` 后将出站收束为 `cancelled`，保留草稿、校验说明与已发生费用，不计入发送额度、不启动平台拒绝冷却。真实 `rejected` 和无法确认点击的异常保持既有语义。唯一且完整的实际回执优先于页面提示；只有本次提交后新增且明确指向发送拒绝的提示才能收束为拒绝，旧 toast、泛化加载错误及自动化账号介绍不会覆盖成功或冒充平台额度拒绝。

## 迁移与恢复

迁移 8 `posting-validation` 为出站新增可空 `validation_json`。旧记录默认 NULL，不回填虚构权限；`begin` 拒绝未校验或不满足当前保守策略的候选，须明确重新校验后才允许保存提交意图。新的候选可以在资源边界内保存超长正文，但不允许发送，也不自动截断、拆帖或重试生成。

恢复时同时保留业务 SQLite、原 `transport-journal.json` 与独立 `posting-preflight-v1.json`，并继续保留现有遗忘／删除账本。不得用旧预检文件覆盖较新的未对账终态。旧应用不能识别 `not_submitted`；发布必须成对更新应用与浏览器，回退前先暂停并完成新类型对账，保留冻结正文及兼容的只读回查工具。没有执行生产发布、真实模型调用或 X 收发。

## 验证

新增服务器用例在 `test/posting-policy.test.ts`，覆盖 Unicode、加权边界、NFC、私信隔离、资源保护、自报权限拒绝、缓存失效、旧列、未提交额度、写盘故障、重启回查、截断回执及纯读接口。本文只说明实现和验证入口，服务器实际执行结果由本轮总实施记录登记；未执行的测试或真实平台路径不声明通过。
