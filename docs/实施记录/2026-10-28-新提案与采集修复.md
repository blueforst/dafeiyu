# 新提案与采集发送修复隔离记录

本轮实现 `add-billing-chart-interaction` 与 `fill-reference-post-gaps`，并处理此前真实测试暴露的采集就绪、提交边界、浏览器资源恢复及诊断问题。所有构建、自动化测试和 Camoufox 验收均在服务器独立目录 `/srv/role-workflow-repair-20261028` 执行，使用同一宿主互斥锁串行运行；没有挂载生产 profile、调用真实模型或新增 X 操作。

## 已实现行为

- 计费三图支持即时提示、键盘浏览、触屏轻点、趋势整列高亮及环形图明细联动，重建时清理监听。
- 公开消息独立保留引用与链接卡片，上文以目标帖为中心，排除其后的回复，扫描自己的帖子时跳过置顶。
- 关键词卡片不调用模型，语义卡片仍共用一次判定；回复固定约束补充不可见资料范围。真实浏览器 JSON 字符串在上下文边界解码，引用、卡片与不完整说明正确进入实际模型请求，正文中的 JSON 不被改写。
- 角色经历只召回已确认发帖与可用人工经历，支持登记、编辑、核对及隐藏。迁移 13 增加两张附加表，保留旧表按位置插入的兼容性；存在人工经历、核对／隐藏信息或任一补录记录时拒绝有损自动回退。
- 按链接补录在下一轮共用公开采集预算核对、去重和优先级入队；暂停时只保存请求。消息详情、补录与经历沿用同一面板账号范围，切号后不读取旧账号详情。
- 模型设置回放冻结两侧配置和 Pi 价格，共用一次语义路由，分侧计量；Key 不进入快照，不改变使用中模型。
- 采集等待原生读取与 SPA 稳定，保留已读的部分结果；私信普通 RPC 失败保留公开结果，安全暂停错误仍中止整轮。新旧来源共用严格原生 ID 去重，旧字段只读，冲突不自动归并，遗忘来源不复活。
- 新的提交前失败按已绑定请求保存未提交终态；提交意图开始后、持久化不确定及历史 unknown 均只允许回查。错误只保存固定代码和阶段，避免丢失定位信息或保存正文、URL。
- 资源恢复仅在轮次安全边界执行，保护 Chat、人工页面和未收束出站；持续压力确认、恢复间隔与次数预算防止反复重启。请求超时保持暂停并等待旧操作退出，不关闭全部页面。
