# 回复提示词实现与集成说明

本记录对应 `improve-reply-prompt-context`。代码实现已通过服务器隔离环境的类型检查、构建及 325/325 项全量回归；五页界面脚本 12 项通过，含动态提醒与试聊分段以及八张浅／深色、桌面／375px针对截图。本提案据此完成 11/13 项，具体日志、位置与最终证据见[后续提案总实施记录](2026-10-28-后续提案.md)。没有执行生产发布、真实模型调用或 X 收发，这些步骤保持未完成。

## 分层与时间

`src/reply-prompt.ts` 提供纯函数 `assembleReplyPrompt()`，生产、试聊和回放复用。system 只包括原固定约束、静态人格与渠道字数规则；user 按角色经历、今日日程、允许范围记忆、当前对话、提醒、本次消息、现在排列。不可信资料保持 JSON 字符串边界。日程只增加北京日期与当前时段，分钟时间只放最后一节。`segments` 的顺序、`role` 和 `content` 与真实请求逐段一致，`stable` 标明可复用前缀段。

任务 1.1 与设计的验证措辞已同步增量规格：跨日只改变 user 的日程日期与末尾时间；system 可以继续复用。修改静态人格或渠道字数规则才会改变对应 system。不将日期重新塞入 system，也不因修订数字变化而新增动态字段。

## 确定性提醒与数据范围

`src/reply-hints.ts` 实现提醒设置默认值、范围校验、可靠平台时间的迟到提醒、书写系统判定、开头提取及颜文字／emoji／波浪号频率统计。迟到提醒要求明确 `timestampReliable:true`；缺失或不可靠时间不推断迟到。

生产生成前可调用 `recentReplySamples(store, accountId, channel, conversationId)`，每次最多读取二十条。公开只查询当前账号的公开回复；私信只查询当前账号的公开回复与当前会话私信。开头最多八个 Unicode 码点，最多十二个不同片段；表情频率只统计当前渠道最近十条。提醒只用于生成约束，不触发额外 LLM 调用，也不在生成后重写结果。

`PersonaService.assemble()` 在语义路由 await 前冻结时间、提醒设置和回复样本。`timestamp`、`timestampReliable`、`conversationId`、`recentReplies`、`promptHints`、`now` 和 `lengthRule` 由轮次快照传入；返回 `meta.hintKinds` 与 `meta.promptVersion` 可写入草稿元数据，缓存读取 token 继续从关联的原调用流水读取。常规日志只保存类别，不保存片段。

## 设置、试聊与回放

`registerPromptHintsRoutes(app,{store})` 注册受全局管理鉴权保护的 `GET/PUT /api/persona/prompt-hints`。读取返回 `{promptHints,revision}`，写入为相同结构，采用独立 `promptHints` 域修订。保存不改变控制状态，越界设置返回 400，修订冲突返回 409。

试聊可显式传未保存的 `promptHints`；最近回复样本只从当前模拟对话的 assistant 消息提取，`sampleSource='preview-dialogue'`，不查询真实回复。返回 `hints` 说明加入的提醒及原因，`postingPolicy` 说明当前账号缓存或普通模拟限制。公开长度策略由应用给 `persona.postingPolicy` 绑定只读缓存，不为试聊刷新浏览器页面。

回放可以传 `routingPurpose='persona-replay'` 与 `routingSource='panel-replay'`，使语义路由费用也计入回放；稳定会话由调用者提供，不改变正常生产 OpenCode 会话逻辑。

## 服务器验证入口

在独立服务器源码副本完成构建后，运行 `node --import tsx --test test/reply-prompt.test.ts test/persona.test.ts`，覆盖稳定前缀、分段实际顺序、北京时段、迟到边界、书写系统、私信范围、表情频率、设置修订、快照、模拟试聊及结构／长度解析分离。`test/persona.test.ts` 仅把三处旧结构断言改为新规格对应位置。

运行 `node test/reply-prompt-report.mjs` 输出十六条合成样本的新旧 system 一致率与提醒比例，标记 `synthetic-offline`，不访问浏览器、不调用模型。真实模型缓存读取 token 前后变化保留为“未测量”；确定性分层测试不能代替服务商实际缓存证据。
