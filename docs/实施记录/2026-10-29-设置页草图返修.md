## 已复现的偏差与原因

| 区域 | 修复前证据 | 原因与修复 |
| --- | --- | --- |
| 表格 | 任务表只占内部宽度 48.6%，日志与历史也停在左侧 | 新表格类没有共用的宽度与列样式；设置页表格明确占满容器，统一行分隔与标题对齐 |
| 日志 | 筛选栏高 188.6px，四个输入各占一行 | DOM 为 `log-toolbar`、`logs-table`，CSS 却写成其他类名；修正对应关系，按内容定宽 |
| 模型 | 工具栏拆为多行，服务商分隔线只到内容底部 | 旧 `.ws-shell .input` 覆盖新输入宽度；修复尺寸优先级，内部栏满高独立滚动 |
| 运行 | 两张卡底边不齐，用量条消失 | 网格 `align-items:start`，用量条和开关的 DOM 类与 CSS 不符；恢复等高、70px 用量条与同行开关 |
| 健康 | 三条告警被横向挤在一起，组标题与指标横排 | 继承旧版 `.health-status`、`.health-group` 规则，且使用不存在的 warning 令牌；改为告警逐行、标题在上、胶囊在下的三列分组 |
| 计费 | 流水收起时仍占大块，热力格缩在中间，柱图变灰黑 | 筛选控件被全宽输入样式覆盖，SVG 限高保留比例产生横向空白，`fill:currentColor` 覆盖模型色；修正控件宽度、按容器等分热力格与恢复图例色 |
| 浏览器与来源 | 桌面占位区仍只占主区约三分之一，账号信息挤在一起 | 旧 `.desk-idle` 的 `max-width`、居中 margin 未被覆盖，新账号行和来源描述类名也不匹配；清除旧宽度与外边距，恢复整行账号、桌面宽度与来源省略 |
| 记忆 | 身份列表分隔线在少量用户下提前结束 | 列只按内容高度布局；内部栏填满可用高度，详情独立滚动，窄屏保留原选择和操作 |
