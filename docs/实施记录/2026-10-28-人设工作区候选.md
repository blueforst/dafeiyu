# 2026-10-28 人设工作区前端候选

## 实现范围

新增共享 `public/js/shell.js` 与隔离的 `--ws-` 样式，提供两栏／三栏、44px 页头、桌面收起持久化、860px 抽屉和详情浮层、焦点圈定／Esc／焦点返回，全部外部文字由文本节点显示。

`views/persona.js` 为模式入口，拆出 `persona-editor.js`、`persona-daily.js` 与 `chat-test.js`。人设模式连接新库接口，提供三种新建、只读预设、单项修订保存、启用确认、复制、改名、删除、全局提醒及按人设回放。日程按日期查看近七天，仅今天编辑或重新生成。试聊采用一个会话对应一个模拟用户的交互，支持公开／私信、已保存人设、先攒消息、同步处理与轮询进度、取消／重试、三标签详情、用户管理和费用。

公开消息每条保留独立的平台线程，不跨线程合并；同一会话内的模拟用户身份、记忆与近期往来连续。私信 hold 消息只取末条入站，其余作为上文。

统一未保存保护覆盖条目、模式、顶层页面和刷新。配置与同项回放之间保留当前草稿，试聊只用已保存版本。
