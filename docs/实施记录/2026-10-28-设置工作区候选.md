# 2026-10-28 设置工作区候选实施

本轮实现 `redesign-settings-workspace`。当前为候选源码，未发布；服务器验证与截图结果由总验收记录补充，未将文件存在当作验收通过。

## 实现范围

- 顶部改为动态、人设、设置三个入口；原记忆、计费和旧分区地址兼容跳转，记忆查询参数原样保留。
- 设置工作区包含运行、数据、浏览器与采集、排查四组共十一项。通过共享 `shell.js` 外壳挂载各模块，当前项有独立主区页头和操作。
- 各项摘要并行读取现有只读接口，单项失败显示“—”。采集来源只在明确打开后读取，账号字数读取缓存，刷新操作只在点击后执行。
- 各模块通过同一个离开保护登记未保存修改；设置项和记忆视图切换、外页切换与刷新均保护。桌面已经连接时切换设置项保留原 DOM 与连接，离开设置页才卸载。
- 运行模式使用两张单选卡；模式切换仅提交已保存值与新模式，不提交未保存发送限制。发送限制加入私信近 24 小时额度和回复时段开关、延迟及当前区间。
- 模型增加已配置与可添加的二级服务商列表及搜索、窄屏选择器；仍保留原添加对话框、连接保存、模型参数、测试与切换规则。
- 记忆按用户记忆、角色经历、策略拆成三种视图，身份列表采用二级列表与窄屏选择器；条目编辑、删除、遗忘、恢复、召回与整理沿用原接口。
- 计费内容、统计和图表交互保留，近 7／30 日控件在页头；新增“试聊”用途，旧接口用途改为“人设试聊（旧接口）”。
- 定时任务使用九行列表，主循环不提供启用开关且保存不带 enabled，宿主健康行只读；任务历史显示关联用量。
- 分级页增加四项指标与近 24 小时私信计数；健康页分指标、账号检查、日报与默认收起的配置；日志、阶段、队列切换到主区页头。

## 兼容与回退

原有设置含义、范围和保存接口不变。回退前端即可恢复五页与长设置页；`ws:settings:*` 浏览器存储可保留。新增 CSS 单独位于 `public/settings-workspace.css`，不影响未挂载设置工作区的页面。
