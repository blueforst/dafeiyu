# 2026-10-28 工作区鲁棒性验收

基线提交为 `860ea880a81dc40e51686f3a5cdf70ba152435b0`。本轮只检查前端工作区生命周期与竞态，不改后端、额度或回复策略，不操作生产，不调用真实模型。

新增服务器专用 `test/workspace-lifecycle-ui-acceptance.mjs`。全部业务 API、SSE 与桌面通过合成资料隔离。探针及存储异常注入通过 app.js 响应前缀在真实页面主世界安装；读取计数和发送 SSE 使用 DOM 事件及 JSON 字符串桥接，并断言实际应用已构造合成 EventSource，避免 Camoufox 执行世界差异造成假结果；本机只编辑和静态阅读，测试由统一服务器流程执行。

## 验收场景

- 延迟整页动态模块，快速离开再返回相同页面，检查只挂载当前代际，旧实例监听和 ResizeObserver 不残留。
- 延迟设置子模块，离开后释放响应，检查不覆盖新页。
- 保存请求成功或失败晚到时，检查旧页面不修改新页通知，也不触发多余的状态刷新。
- 连续更换离开确认目标，保留编辑后原输入不丢，放弃时只进入最后目标。
- 一百次重复 SSE 事件，检查摘要批次有界、最后状态正确，没有额外采集来源或模型请求。
- 桌面连接跨十一个设置项保持；离开设置页只卸载一次，不隐式释放或重复接管。
- localStorage 读写抛错时，工作区仍可切换与收起，窄屏抽屉可用。
- 默认一百轮、最多一百二十轮，在三页和十一个设置项间交替切换；比较全局监听、ResizeObserver、间隔计时器、SSE 实例与工作区节点数量。只在明确打开采集来源项时允许相应只读请求。

## 冻结基线的红证据

根代理在服务器对冻结的 `860ea88` 前端执行默认一百轮，八组中五组通过、三组失败；实际主世界探针与合成 SSE 标记有效。证据为服务器产物 `workspace-lifecycle-red/workspace-lifecycle-ui-acceptance.json` 和 `robust-workspace-red.log`。

- 动态导入往返竞态：同名页面的旧导入也通过了页名校验，观察到两个活动 ResizeObserver，本应只有一个。
- 保存响应晚到：运行设置失败、健康设置成功、模型连接成功均会覆盖新页通知；模型还会在离开后额外读取全局状态。
- 重复 SSE：在一批摘要仍等待响应时，同时出现十二批摘要读取，超出单批在途的验收要求。

慢设置子模块、快速离开确认、桌面连接保留及一次清理、存储异常和一百轮资源不增长均已在基线通过，不为这些路径额外重构。

## 最小修复

- `app.js` 以当前挂载记录的对象身份验证异步整页导入；离开后再返回同名页面属于不同记录，旧导入不再挂载或显示迟到错误。同页子路由仍沿用当前挂载并读取最新路由。
- 设置摘要同一时刻只保留一批请求。期间收到的事件合并为一次尾刷新，旧代际结果不覆盖新状态；卸载后不启动尾刷新。
- 运行、健康和模型设置在异步保存及后续读取返回后核对 `alive`；已卸载时不再显示全局通知、触发新的状态读取或执行后续页面动作。保存请求本身的后端结果不被客户端撤销。

## 修复验证

根代理在服务器对修复后的候选执行同一脚本，八组全部通过，`errors=[]`；实际页面主世界标记和合成 EventSource 构造断言通过。证据为服务器产物 `workspace-lifecycle-green/workspace-lifecycle-ui-acceptance.json` 和 `robust-workspace-green.log`。红证据保留，未回写为旧版本通过。
