# 角色互动工作流

面向 **X（Twitter）单账号运营**的自托管 AI 角色互动工具。通过网页管理人设、处理消息、生成回复和维护用户记忆，支持人工审核与自动发送，并记录模型用量和费用。

| 页面 | 可以做什么 |
| --- | --- |
| **动态** | 查看公开互动和私信，审核、编辑回复，跟进处理状态与回执 |
| **人设** | 创建角色、安排虚构日程，用独立测试会话调整聊天效果 |
| **设置** | 配置模型、发送额度、回复时段、记忆和定时任务，查看费用与日志 |

## 最快开始使用

准备好：**已部署的后台地址和登录凭据、一个 X 账号、可用的模型 API Key**。首次自建请先看下方部署入口。

1. **登录 X**：打开后台，进入 **设置 → 浏览器接管 → 接管并连接**，在远程浏览器中完成登录，再点击 **释放**。
2. **配置模型**：进入 **设置 → 模型**，添加服务商和 API Key，选择模型，测试通过后 **设为使用中**。
3. **创建人设**：进入 **人设**，从空白或内置预设新建，编辑并保存。
4. **先试聊**：切到 **人设 → 试聊**，新建测试会话，选择已保存的人设进行对话。满意后将该人设 **设为使用中**。试聊使用真实模型，会计费，但不会向 X 发送消息。
5. **开始处理消息**：在 **设置 → 运行与发送** 选择 **草稿模式**，检查发送额度和回复时段，再点击右上角 **启动**。到 **动态** 审核回复，点击发送后进入队列；需要自动回复时再切换为 **自动模式**。

释放接管、保存设置和批准草稿都不会自动启动工作流。若消息仍在等待，先检查顶部运行状态、回复时段和通道额度；显示 **待回查** 的消息会核对原提交结果，不会自动重发。

模型连接测试和试聊都会产生实际调用费用，可在 **设置 → 计费** 查看。当前图片不参与视觉识别；新版 X Chat 的实际收发验证范围见[私信处理说明](docs/新Chat私信处理.md)。

## 自行部署

使用 Linux 服务器和 Docker Compose，应用与 Camoufox 浏览器分别运行在独立容器中。首次安装需要准备宿主数据目录、配置、密钥、维护组，以及带登录认证的 HTTPS 反向代理。

- **容器与配置**：[compose.yaml](compose.yaml) · [环境变量示例](.env.example) · [应用配置示例](config.example.json)
- **访问入口**：[Nginx 配置示例](deploy/nginx.conf.example)；按自己的域名或地址、证书及认证信息修改。
- **宿主准备**：[维护桥接与目录权限](docs/宿主维护桥接.md) · [数据迁移与恢复](docs/迁移与恢复.md)
- **构建与测试**：在服务器使用[受限执行入口](dev/server-heavy.sh)串行执行，保留宿主资源余量；版本与升级状态以[发布记录](docs/发布记录/)为准。
