# 虚构角色日程增量规格（人设工作区）

## MODIFIED Requirements

### Requirement: 人设页日程展示与编辑

系统 MUST 在人设页“日程”模式中以日期为左栏条目列出当前账号近七日的虚构日程，今天置顶，每项标明生成、已编辑或失败无日程。选中某天后，主区 MUST 展示当天时间轴、当前时段（仅今天）、三餐、活动、心情、生成来源、生成所用人设、更新时间、修订号、生成状态和关联费用。今天的日程 MUST 提供编辑及重新生成操作，过去日期只读。调度时间引用设置页定时任务分区的同一设置，并可从左栏跳转到该设置。生成所用人设 MUST 在生成时记录；本版本之前生成的日程显示“未记录”。

#### Scenario: 手动重新生成
- **WHEN** 管理员主动请求重新生成且没有同日生成任务正在执行
- **THEN** 页面展示进行状态，新结果生效并记录本次费用和所用人设

#### Scenario: 查看过去某天
- **WHEN** 管理员在左栏选中三天前的日程
- **THEN** 主区只读显示那天的时间轴和来源，没有编辑和重新生成按钮，也不高亮当前时段

#### Scenario: 某天生成失败
- **WHEN** 某天自动生成三次均失败
- **THEN** 左栏该日期标明失败无日程，主区显示失败说明，不沿用前一天的内容
