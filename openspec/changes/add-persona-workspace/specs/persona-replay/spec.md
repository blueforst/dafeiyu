# 人设回放增量规格（人设工作区）

## MODIFIED Requirements

### Requirement: 采用候选人设

回放 MUST 从人设模式中某个人设的页头发起，以该人设编辑器中的当前内容为候选，以该人设在人设库中的已保存版本为“已保存人设”基线；“以历史实际回复为基线”的选项保持不变。回放记录 MUST 显示发起回放的人设名称。管理员 MUST 能把候选草稿通过正常保存流程保存到发起回放的那个人设；若回放开始后该人设已被修改，保存必须因修订冲突被拒绝并提示重新回放或手动合并。采用候选 MUST NOT 改变哪个人设处于使用中；只有该人设本身就是使用中人设时，保存后才在下一轮影响生产。保存后沿用下一轮生效语义，不恢复暂停的业务。

#### Scenario: 修订冲突
- **WHEN** 回放运行期间该人设已被另一次保存修改
- **THEN** 采用候选被拒绝，页面提示修订已变化

#### Scenario: 以未使用人设的已保存版本为基线
- **WHEN** 管理员在未使用的“通用 · 改”中修改说话风格后发起回放，基线选择已保存人设
- **THEN** 基线使用“通用 · 改”的已保存版本，而不是使用中人设；回放记录标明“通用 · 改”

#### Scenario: 对未使用的人设采用候选
- **WHEN** 管理员从未使用的“大肥鱼 · 温柔版”发起回放并采用候选
- **THEN** 候选内容保存到“大肥鱼 · 温柔版”，修订号加一；使用中人设和生产回复不变
