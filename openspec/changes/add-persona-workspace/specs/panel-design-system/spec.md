# 面板统一设计规格

## Purpose

为面板各页面提供同一套视觉基础和工作区版式：左栏列表加主区，按需带右栏，在顶栏下方铺满视口，左右栏都能收起，窄屏可用，浅色和深色一致。本提案先用于人设页，设置页和动态页由后续提案迁移到同一套设计。

## ADDED Requirements

### Requirement: 统一视觉基础

使用新设计的页面 MUST 共用同一套颜色、字号、圆角和组件样式，并同时提供浅色和深色两套取值，跟随系统主题切换。组件至少包括：侧栏列表项（含选中、悬停、次要文字和右侧时间或状态）、分段切换、徽标、主按钮与普通按钮、内容卡片、输入框和对话流消息。页面 MUST NOT 使用 DeepSeek 或 DeepSeek Harness 的标志、名称或品牌素材。

#### Scenario: 切换系统深色模式
- **WHEN** 管理员把系统切换为深色模式后打开人设页
- **THEN** 侧栏、主区、右栏、按钮和对话气泡都使用深色取值，文字与背景对比清晰，没有残留的浅色块

#### Scenario: 同类组件外观一致
- **WHEN** 管理员依次查看人设、日程、试聊三种模式的左栏
- **THEN** 三者的列表项高度、选中底色、次要文字和时间样式相同

### Requirement: 工作区版式

使用新设计的页面 MUST 在全局顶栏下方铺满剩余视口，不留外框和页边距。左栏和主区固定存在，右栏只在页面或模式需要查看某一项详情时出现。各栏 MUST 共用同一行页头：左栏页头放模式切换或分组标题，主区页头放当前条目名称和操作，右栏页头放其标签。只有主区和各栏自身内容滚动，整页不滚动。

#### Scenario: 两栏模式
- **WHEN** 管理员在人设页打开人设模式
- **THEN** 页面只有左栏和主区，主区占满左栏右侧的全部宽度

#### Scenario: 三栏模式
- **WHEN** 管理员切换到试聊模式
- **THEN** 页面出现右栏，三栏页头在同一行对齐

#### Scenario: 长内容滚动
- **WHEN** 试聊对话超过一屏
- **THEN** 只有对话区滚动，顶栏、页头和输入框保持可见

### Requirement: 侧栏收起

左栏和右栏 MUST 都能通过页头按钮收起和展开；收起后主区占用腾出的宽度，当前选中的条目和未保存的编辑不受影响。页面 MUST 在当前浏览器中记住每个页面的收起状态，再次打开时恢复；浏览器存储不可用时按展开状态显示，功能不受影响。收起和展开按钮 MUST 可用键盘操作，并有可读的名称。

#### Scenario: 收起左栏编辑人设
- **WHEN** 管理员在编辑人设时收起左栏
- **THEN** 配置页变宽，编辑内容和未保存标记保持不变；再次展开后左栏仍选中同一个人设

#### Scenario: 刷新后保持收起
- **WHEN** 管理员收起试聊右栏后刷新页面
- **THEN** 试聊右栏保持收起，左栏保持原状态

#### Scenario: 浏览器禁止存储
- **WHEN** 浏览器禁止网站存储
- **THEN** 页面按展开状态显示，收起和展开仍可使用，只是刷新后不记住

### Requirement: 窄屏可用

宽度不超过 860px 时，左栏 MUST 默认收起，改为从左侧滑出的抽屉，选中条目后自动关闭；右栏 MUST 改为覆盖在主区上的浮层，关闭后回到主区。375px 宽度下页面 MUST NOT 出现整体横向滚动，主要操作都能完成。

#### Scenario: 手机上试聊
- **WHEN** 管理员在 375px 宽度下打开试聊，从抽屉选择测试用户后发送一条消息
- **THEN** 抽屉关闭，对话和输入框占满宽度，消息可以发送，页面没有横向滚动

#### Scenario: 手机上查看本轮详情
- **WHEN** 管理员在 375px 宽度下点开某一轮回复的详情
- **THEN** 详情以浮层显示，关闭后回到原来的对话位置

### Requirement: 统一状态提示

使用新设计的页面 MUST 用同一套样式显示加载中、空列表、读取失败（带重试）和未保存修改；离开有未保存修改的条目或页面时，MUST 让管理员选择保留编辑或明确放弃，不静默丢失内容。外部来源的文字 MUST 按纯文本显示。

#### Scenario: 切换到另一个人设时有未保存修改
- **WHEN** 管理员修改了一个人设但未保存，然后在左栏点击另一个人设
- **THEN** 页面询问保留编辑还是放弃；选择保留时停留在原人设，编辑内容不变

#### Scenario: 列表读取失败
- **WHEN** 测试用户列表读取失败
- **THEN** 左栏显示失败说明和重试按钮，主区不显示过期内容
