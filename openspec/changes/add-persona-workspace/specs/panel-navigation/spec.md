# 面板导航增量规格（人设工作区）

## MODIFIED Requirements

### Requirement: 页面职责和同源设置

系统 MUST 在人设页“日程”模式管理日程内容、在设置页定时任务分区管理生成计划，两处共享同一有效设置和结果；运行模式、模型、定时任务、发送限制和记忆策略只在设置页维护，各自只有一份可编辑配置。人设页 MUST 提供人设、日程、试聊三种模式，地址分别对应人设、日期和测试用户；旧地址 `#/persona/persona`、`#/persona/daily`、`#/persona/preview` MUST 分别打开人设、日程和试聊模式，不显示空白页或错误。

动态页 MUST 不显示日志；设置页“排查问题”区 MUST 集中展示行式日志，包含时间、事件和说明，并保留筛选及暂停实时能力，同时提供阶段记录、当前队列和任务执行历史。

#### Scenario: 查看日志
- **WHEN** 管理员从动态页进入设置页“排查问题”区
- **THEN** 动态页没有日志区，排查问题区提供行式日志列表、阶段记录、队列和任务执行历史

#### Scenario: 调整日程生成时间
- **WHEN** 管理员在设置页定时任务分区保存新的生成时间
- **THEN** 人设页“日程”模式显示同一时间，不出现第二份可冲突的调度配置

#### Scenario: 打开旧试聊地址
- **WHEN** 管理员访问旧地址 `#/persona/preview`
- **THEN** 人设页以试聊模式打开，选中最近活动的测试用户；没有测试用户时显示新建入口

#### Scenario: 直接打开某个测试用户
- **WHEN** 管理员访问某个测试用户的试聊地址
- **THEN** 人设页以试聊模式打开并选中该测试用户；该用户已被删除时显示说明和返回列表的入口
