# 模型计费增量规格（计费页紧凑排版）

## MODIFIED Requirements

### Requirement: 计费页汇总与流水

计费页 MUST 提供今日、近 7 日、近 30 日、本月和自选日期范围的请求数、token、美元估算及未定价数量，展示每日用量、按模型／用途汇总及有限分页调用明细；筛选口径必须一致。范围切换与刷新 MUST 位于页头右侧，页面底部不再重复刷新按钮与口径说明。页面自上而下为：汇总条；每日用量与用量占比并排（宽度不超过 1100px 时上下排列）；活动热力图压成一条；调用流水默认收起。调用流水收起时标题行显示当前范围与调用次数，展开后才请求明细；用途与自选日期筛选位于调用流水的标题行。

#### Scenario: 切换日期范围
- **WHEN** 管理员在页头选择近 30 日
- **THEN** 汇总、每日用量、占比和流水使用同一范围，金额注明 Pi 目录估算

#### Scenario: 只有未定价请求
- **WHEN** 当前范围内没有可估价调用
- **THEN** 页面明确显示未定价数量和未知费用，不把估算总额零误作全部免费

#### Scenario: 默认进入计费页
- **WHEN** 管理员在 1440×868 窗口打开计费页且未选择范围
- **THEN** 不滚动即可看到汇总条、近 7 日每日用量与占比、热力图和收起的调用流水标题行；流水明细尚未请求

### Requirement: 按模型每日趋势

计费页 MUST 以柱状图展示所选范围（近 7 日或近 30 日等）的每日用量，每天一根柱，按模型堆叠，最多显示五个模型，其余合并为其他模型；缺少调用的日期显示为零高度，日期轴保持连续；可在 token 与可估算费用之间切换，费用视图不得把未定价调用计为零。图表高度 MUST 不超过 220px。指针悬停在某天的柱或其所在列区域时，MUST 高亮该列并显示提示框：标题为日期、星期及合计，每个模型一行（色块、名称、数值），按数值从大到小排列，不列出数值为零的模型。键盘可左右移动到各天并显示同样的提示框。提示框数值使用中文紧凑单位并带单位名称。

#### Scenario: 悬停某一天
- **WHEN** 管理员把指针移到近 7 日图中某一天所在的列，不必对准柱子
- **THEN** 该列高亮，提示框列出该日各模型的 token 与合计

#### Scenario: 某日没有调用
- **WHEN** 近 7 日中某一天没有任何调用
- **THEN** 该日柱高为零，日期轴保持连续，悬停时提示框只显示合计为 0

#### Scenario: 切换到费用视图
- **WHEN** 某模型全部调用未定价且管理员切换到费用
- **THEN** 该模型标注未定价，不画成 0 美元的柱，悬停提示框中该模型显示“未定价”

### Requirement: 计费数字与主题

计费页 MUST 用中文紧凑单位（万、亿）展示 token，数字使用等宽字体、单位文字弱化；美元金额 MUST 最多保留两位有效小数，悬停或聚焦时显示精确值。图表配色在浅色与深色主题下均可辨认，375px 宽度下不产生整体横向溢出。

#### Scenario: 小额费用
- **WHEN** 近 7 日平均每次回复费用为 0.0002454 美元
- **THEN** 汇总条显示 $0.00025，悬停显示 $0.0002454

#### Scenario: 深色主题窄屏
- **WHEN** 管理员在深色主题、375px 宽度打开计费页
- **THEN** 汇总条纵向排列，每日用量与占比上下排列，热力图等分宽度且无横向滚动，图表颜色清晰可辨

#### Scenario: 表格查看和展开调用
- **WHEN** 管理员展开调用流水
- **THEN** 显示时间、状态、模型、账号／用途、耗时、Token、费用七列摘要，每行约 48px；缺失资料以“—”表示，未定价明确标注
- **AND** 点击记录或使用回车、空格可展开与收起该条分项和关联资料，展开无需读取新接口
- **AND** 窄屏保持页面宽度，宽表只在自身容器内横向滚动

#### Scenario: 切换范围时旧流水请求仍在进行
- **WHEN** 管理员改变日期或用途，前一范围的流水响应后到达
- **THEN** 当前范围仍能发起请求，旧结果及旧错误不会覆盖新范围；分页只追加同一范围的记录
