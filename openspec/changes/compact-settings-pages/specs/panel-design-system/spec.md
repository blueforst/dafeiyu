# 面板统一设计增量规格（设置页紧凑排版）

## ADDED Requirements

### Requirement: 设置页紧凑排版

设置页各项 MUST 按内容给控件定宽：填写不超过四位数字的输入框宽度不超过 96px，时间输入不超过 96px，不得拉满整行；勾选项使用与说明同一行的开关。宽度大于 1100px 时，相互独立的内容 MUST 以两列卡片排列铺满主区，不得只占左半屏而右侧留空。列表与表格 MUST 一行一项，次要信息用浅色写在同一行，不得为每项堆叠三四行小字。列表、排队、过滤等区域为空时 MUST 合并为一行说明，不单独占用整块卡片。美元金额 MUST 最多保留两位有效小数（例如 $0.04840811 显示为 $0.048），悬停或聚焦时显示精确值；未知值显示“—”，不写“未知”。宽度不超过 860px 时两列改为单列，页面不得整体横向溢出。

#### Scenario: 运行与发送的数字输入
- **WHEN** 管理员在 1440×868 窗口打开“运行与发送”
- **THEN** 发送上限的四个输入框都不超过 96px 宽，发送上限与回复时段两张卡片并排，整页无需滚动

#### Scenario: 小额费用
- **WHEN** 某个汇总值为 0.04840811 美元
- **THEN** 页面显示 $0.048，悬停显示 $0.04840811

#### Scenario: 窄屏
- **WHEN** 管理员在 375px 宽度打开任一设置项
- **THEN** 卡片单列排列，没有整体横向滚动

### Requirement: 高级设置默认收起

平时不需要修改的参数 MUST 放在所在设置项底部的“高级设置”折叠块中（列表加详情的设置项放在页头“高级设置”按钮打开的窗口中），默认收起；收起时标题行 MUST 用一行浅色文字列出其中各项及当前值。展开状态 MUST 按设置项记在本浏览器，下次打开该项时恢复；读取不到记录时保持收起。高级设置中的参数与主区参数一起保存，保存规则、取值范围和生效时机不变；有未保存修改时离开该项仍先询问保留或放弃。

#### Scenario: 收起时也能看到当前值
- **WHEN** 管理员打开“消息分级与过滤”，高级设置处于收起状态
- **THEN** 标题行显示“消息时效 3 小时、同文重复降优先阈值 3”，不展开也能知道当前值

#### Scenario: 记住展开状态
- **WHEN** 管理员在“运行与发送”展开高级设置后切换到其他设置项，再切回来
- **THEN** 高级设置仍是展开状态；在另一个浏览器首次打开时为收起状态

#### Scenario: 高级参数未保存
- **WHEN** 管理员修改了高级设置中的每轮最多处理但未保存，点击左栏“模型”
- **THEN** 页面询问保留编辑还是放弃

### Requirement: 行内操作显隐

设置页列表和表格中每行的操作按钮（设为使用中、测试、编辑、单次执行等）MUST 在该行悬停、键盘聚焦到行内或该行被选中时显示，其余时候隐藏但保留占位，避免列宽跳动；触屏（`hover:none`）下点按一行先选中再显示操作。需要关注的状态（测试失败、执行失败、未启用且会发到 X 等）MUST 始终直接显示，不随悬停隐藏。带计费的操作 MUST 继续显示“计费”标记。

#### Scenario: 悬停一行
- **WHEN** 管理员把指针移到模型表中一个未使用的模型行
- **THEN** 该行右侧出现“设为使用中”“测试（计费）”“编辑”，移开后消失，表格列宽不变

#### Scenario: 键盘操作
- **WHEN** 管理员用 Tab 键把焦点移到某行的“编辑”按钮
- **THEN** 该行的操作按钮全部可见，焦点按钮有可见描边

#### Scenario: 触屏
- **WHEN** 管理员在触屏设备上点按定时任务中的“虚构日程”一行
- **THEN** 该行被选中并显示“单次执行（计费）”，再次点按按钮才执行
