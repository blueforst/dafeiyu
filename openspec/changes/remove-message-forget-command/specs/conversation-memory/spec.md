# 对话记忆增量规格（取消消息里的遗忘指令）

## MODIFIED Requirements

### Requirement: 遗忘与恢复记录

系统 MUST 在记忆页支持遗忘并停止记录、恢复后续记录，以及使遗忘前正在生成的旧摘要失效；独立遗忘记录在恢复旧数据库后仍必须生效。用户消息的内容 MUST NOT 改变遗忘状态，“忘了我吧”“重新记住我”这类消息按普通消息处理。用户要求忘掉自己或删除记录时，固定系统约束 MUST 要求回复不声称已经忘记或删除，并说明记录由运营者管理。

#### Scenario: 遗忘时仍有摘要在生成
- **WHEN** 用户被遗忘后旧摘要请求才返回
- **THEN** 系统拒绝写回该摘要并继续阻止记录

#### Scenario: 恢复记录
- **WHEN** 已遗忘用户重新允许记录
- **THEN** 系统可以记录之后的新消息，不自动恢复此前已删除的内容

#### Scenario: 恢复旧数据库
- **WHEN** 旧数据库包含已经遗忘的用户内容
- **THEN** 系统在继续处理前重放独立遗忘记录并移除对应内容

#### Scenario: 用户在消息里说“忘了我吧”
- **WHEN** 未被遗忘的用户发来“忘了我吧”
- **THEN** 系统照常记录并处理这条消息，可以回复，该用户的遗忘状态不变

#### Scenario: 已遗忘用户发“重新记住我”
- **WHEN** 已被管理员遗忘的用户发来“重新记住我”
- **THEN** 系统仍不记录这条消息，该用户保持遗忘，只能由管理员在记忆页恢复

#### Scenario: 用户要求删除记录
- **WHEN** 用户请角色把和自己的聊天记录删掉
- **THEN** 回复使用的固定系统约束要求不声称已经删除，并说明记录由运营者管理
