# 回复提示词结构实施任务

本轮完成代码实现及服务器隔离验证，已完成 11/13 项；真实样本／模型缓存测量与生产发布保持未完成。证据见[后续提案总实施记录](../../../docs/实施记录/2026-10-28-后续提案.md)与[回复提示词验收映射](../../../docs/实施记录/2026-10-28-回复提示词集成.md)。规格见 [reply-prompt-context](specs/reply-prompt-context/spec.md)，实现边界见 [design.md](design.md)。构建、自动化测试和界面验收均在服务器隔离环境执行；真实模型的缓存测量和生产发布另需授权。

## 1. 分层顺序与时间

- [x] 1.1 重构 `persona.assemble()` 为 system（固定约束、静态人格、渠道固定规则）与 user 七个分节的固定顺序，旧拼接路径同步；以服务器单元测试验证同账号同渠道同日不同命中时 system 字节一致、跨日时 user 的日程日期及当前时间变化而 system 保持稳定、换静态人设后 system 使用新内容为验收。
- [x] 1.2 实现北京时间、星期与时段名称，日程节只写时段、末尾写到分钟；以服务器单元测试覆盖各时段边界及 UTC 15:30／北京 23:30 场景为验收。
- [x] 1.3 把命中模块正文移入提醒区并加入回复判断提醒，更新 `docs/人设与日程.md` 的提示词结构说明；以服务器测试验证命中正文不出现在 system、提醒位于当前对话之后且语义触发调用次数不变为验收。

## 2. 确定性动态提醒

- [x] 2.1 新增 `src/reply-hints.ts` 并实现迟到提醒；以服务器单元测试覆盖阈值前后、不可靠时间不提醒、阈值配置范围为验收。
- [x] 2.2 实现书写系统判定与语言提醒，附繁体特有字形表和样本；以服务器回归覆盖简体、繁体、日文（含假名）、韩文、英文、纯表情和中英混合样本为验收。
- [x] 2.3 实现最近回复开头提取与渠道隔离；以服务器测试验证公开只取公开、私信只取公开与同会话、片段长度与去重、不写入常规日志为验收。
- [x] 2.4 实现颜文字、emoji、“～”识别与频率上限；以服务器样本测试覆盖连续颜文字、上限边界、半角波浪号合并统计为验收。
