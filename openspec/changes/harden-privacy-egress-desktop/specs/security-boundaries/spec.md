## Purpose

为现有角色工作流补齐隐私撤销、持久明文清理、模型网络出口以及人工桌面互斥边界，在并发生成、恢复旧数据或平台结果未知时仍保持明确可验证的权限、保留与防重复提交约束。

## ADDED Requirements

### Requirement: 撤销约束在途生成与提交

系统 MUST 冻结实际使用的记忆与关联修订，并在生成后及最终提交前复核。修订失效的未提交结果 MUST 不发送，且不能因批准旧草稿恢复撤销内容。

#### Scenario: 生成期间撤销关联或删除记忆
- **WHEN** 已读取背景的生成期间关联被解除、更换、关联侧遗忘或记忆被删除
- **THEN** 旧结果失效，后续按新范围生成可正常处理

### Requirement: 出站副本遵循遗忘与保留期

系统 MUST 将 outbox 明文纳入遗忘、到期和恢复重放；已完成或取消的出站只保留防重发最小材料。submitting/unknown MUST 不被重置或重复发送，核对材料 MUST 最小化并有明确保留边界。

#### Scenario: 遗忘后恢复旧数据库
- **WHEN** 旧数据库包含遗忘范围的出站副本并重新启动
- **THEN** 系统重放账本清理副本，保留唯一标识与未知状态，不复活明文或自动重发

### Requirement: 模型请求统一出口限制

系统 MUST 校验模型目标 URL、全部解析地址和实际连接，默认禁止跳转；URL 凭据、query/hash、私网、回环、链路本地及保留地址不得绕过限制。内部模型 MUST 使用明确目标及端口允许配置。

#### Scenario: 域名或重定向指向内网
- **WHEN** 模型地址解析含受限地址、解析在连接时变化或响应跳转至受限目标
- **THEN** 请求在访问受限目标之前失败，错误不暴露密钥

### Requirement: 出站内容一致检查

系统 MUST 统一检查带协议和不带协议的域名、短链接、国际化域名及额外账号提及，草稿解析、最终出站和回放指标必须一致。

#### Scenario: 模型输出裸域名
- **WHEN** 模型输出含可识别裸域名或短链接
- **THEN** 草稿及最终出站均阻止该内容

### Requirement: 人工桌面与自动运行互斥

系统 MUST 在释放人工接管开始时拒绝新桌面连接，并关闭旧代次已建立和正在建立的连接；恢复自动运行不能保留旧桌面通道。

#### Scenario: 释放期间并发重连
- **WHEN** 一个客户端释放接管，其他标签同时建立或重连桌面
- **THEN** 非当前 manual 代次的通道被拒绝或关闭，paused/running 下不能继续传输
