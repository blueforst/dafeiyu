## Context

当前生产为 0.1.28.1，schema 14。旧报告行号需按当前源码重核。所有构建、自动回归和批量渲染在服务器执行。

## Decisions

1. 复用现有按账号、身份及渠道维护的记忆失效修订，覆盖关联双方。生成前冻结、生成后复核，并将修订写入草稿；发送前及浏览器提交前重新核对。撤销后清除未提交旧正文，旧 unknown 不重发。
2. 出站保留唯一键、目标、状态及必要哈希。终态清除正文，prepared 先取消再清除；submitting/unknown 不复位，清除入站正文并限定核对材料与保留边界。初始化重放遗忘账本，恢复旧库时同样清理。历史备份不能承诺原地撤销，须记录保留安排。
3. 模型出口共用策略，校验 URL、全部 DNS 结果及实际连接地址。默认禁止重定向，内部模型通过明确目标和端口配置允许。验证使用合成 HTTP 服务，不探测真实内网。

   Pi 的 Google 适配器明确拒绝自定义 fetch，因此实际生成通过 AsyncLocalStorage 限定的 fetch 保护范围统一出口；普通应用 RPC 不在此范围。强制模型使用 SSE，避免 WebSocket 传输绕过 HTTP 连接策略。合成协议服务只允许其本次实际监听的 origin 和端口。
4. 链接及提及识别复用 twitter-text，生成解析、最终校验和回放共用。
5. release 在任何异步步骤前退出 manual。桌面代理按控制代次关闭已建立或正在建立的连接，握手完成后再校验。
6. 浏览器升级先核对内核、上游回补与有效安全配置，再进行隔离配对验收。保留 profile 及设备身份，禁止为通过测试绕过平台验证。

   生产实读 156.0.1-beta.36，恢复后核对到官方新发布的158.0.1-beta.41，启动器改为配对0.5.9-beta.6。构建期使用固定大小及官方SHA256、流式下载和磁盘解包，避免旧解包方式一次读入约1.3GB。恢复安全偏好不能代替实际二进制和配置验证；升级尚未验收完成。恢复步骤及证据见 docs/实施记录/2026-10-30-安全返修候选与恢复交接.md。

## Risks / Trade-offs

撤销可能导致已花费的模型结果被丢弃；这是隐私边界要求。终态明文清理不可逆，回退不能恢复被删除内容。旧 unknown 保持保守阻断。出口限制可能拒绝旧内网模型，需明确允许目标。内核更新必须与启动器和 Playwright 配对。

## Migration Plan

优先复用版本化 runtime 和兼容扩展；必要字段通过只加字段迁移。发布前冻结来源、保留旧镜像和证据，成对部署并保留最新控制。回退不删除遗忘及提交账本，不反向恢复明文。

## Validation

分别覆盖生成期间 unlink、换关联、关联侧遗忘、删除记忆，以及发送等待期间撤销；覆盖六种出站状态、重启和恢复；覆盖私网、IPv6、DNS 变化、重定向、裸域名和实际隔离 VNC 竞争。全套回归、前端适用回归与生产读回分开记录。没有调用模型时费用为零，不把替身当作真实平台发送。
