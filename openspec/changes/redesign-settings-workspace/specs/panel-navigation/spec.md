# 面板导航增量规格（设置页改版）

## MODIFIED Requirements

### Requirement: 一级页面导航

管理面板 MUST 恰好提供动态、人设、设置三个一级页面，默认打开动态页。原记忆页和计费页的全部功能并入设置页的“记忆”“计费”项，原模型、主程序、定时任务三页的内容也在设置页对应项中。旧地址 MUST 跳转到新位置，不显示空白页或错误：

- `#/overview` 打开动态页；
- `#/model`、`#/tasks`、`#/browser` 分别打开设置页“模型”“定时任务”“浏览器接管”项；
- `#/program` 打开“日志阶段与队列”项；
- `#/memory` 打开“记忆”项，并保留其查询参数所指定的账号、用户和渠道；
- `#/billing` 打开“计费”项。

#### Scenario: 默认进入概览
- **WHEN** 管理员打开未指定页面的面板地址
- **THEN** 系统显示动态页，导航恰好包含动态、人设、设置三项

#### Scenario: 页面地址直接访问
- **WHEN** 管理员访问旧地址 `#/model`、`#/program`、`#/tasks`、`#/billing` 或 `#/overview`
- **THEN** 前四者打开设置页的模型、日志阶段与队列、定时任务、计费项，`#/overview` 打开动态页

#### Scenario: 旧记忆链接带用户参数
- **WHEN** 管理员打开一个指向某用户私信记忆的旧 `#/memory?...` 链接
- **THEN** 设置页“记忆”项打开并选中该用户的私信身份

#### Scenario: 直接访问设置项
- **WHEN** 管理员打开 `#/persona` 或任一设置项地址
- **THEN** 系统打开对应页面或设置项，不要求先经过动态页

### Requirement: 浏览器人工接管

系统 MUST 在设置页“浏览器接管”项提供浏览器人工接管，排空自动操作并进入接管后才允许桌面连接；发起接管、查看接管状态、连接桌面和释放接管 MUST 都在该项完成。释放接管必须断开交互连接并保持暂停。左栏该项的摘要 MUST 随状态显示是否处于人工接管。浏览器未登录或需要人工处理时，动态页 MUST 显示提示并链接到该项。旧地址 `#/browser` MUST 打开该项。

#### Scenario: 非接管状态连接桌面
- **WHEN** 管理员在非人工接管状态访问桌面入口
- **THEN** 系统拒绝连接并提示先接管

#### Scenario: 释放人工接管
- **WHEN** 管理员在浏览器接管项释放已连接的人工接管
- **THEN** 浏览器交互连接断开，自动处理不恢复，顶部栏显示“已暂停”且“启动”可用

#### Scenario: 已接管但未连接桌面时释放
- **WHEN** 系统处于人工接管但管理员尚未连接桌面，在浏览器接管项点击释放接管
- **THEN** 系统回到已暂停，左栏该项摘要不再显示人工接管

#### Scenario: 需要人工登录
- **WHEN** 浏览器状态显示需要人工处理验证码或登录
- **THEN** 动态页显示提示，点击后打开设置页浏览器接管项

### Requirement: 页面职责和同源设置

系统 MUST 在人设页“日程”模式管理日程内容、在设置页“定时任务”项管理生成计划，两处共享同一有效设置和结果；运行模式、模型、定时任务、发送限制和记忆策略只在设置页维护，各自只有一份可编辑配置。人设页 MUST 提供人设、日程、试聊三种模式，地址分别对应人设、日期和测试用户；旧地址 `#/persona/persona`、`#/persona/daily`、`#/persona/preview` MUST 分别打开人设、日程和试聊模式，不显示空白页或错误。

动态页 MUST 不显示日志；设置页“日志阶段与队列”项 MUST 集中展示行式日志，包含时间、事件和说明，并保留筛选及暂停实时能力，同时提供阶段记录和当前队列；任务执行历史在“任务执行历史”项中提供。

#### Scenario: 查看日志
- **WHEN** 管理员从动态页进入设置页“日志阶段与队列”项
- **THEN** 动态页没有日志区，该项提供行式日志列表、阶段记录和队列，任务执行历史可从左栏打开

#### Scenario: 调整日程生成时间
- **WHEN** 管理员在设置页“定时任务”项保存新的生成时间
- **THEN** 人设页“日程”模式显示同一时间，不出现第二份可冲突的调度配置

#### Scenario: 打开旧试聊地址
- **WHEN** 管理员访问旧地址 `#/persona/preview`
- **THEN** 人设页以试聊模式打开，选中最近活动的测试用户；没有测试用户时显示新建入口

#### Scenario: 直接打开某个测试用户
- **WHEN** 管理员访问某个测试用户的试聊地址
- **THEN** 人设页以试聊模式打开并选中该测试用户；该用户已被删除时显示说明和返回列表的入口

### Requirement: 主题与窄屏可用性

三个页面 MUST 支持系统浅色／深色、375px 宽度、加载／空数据／错误状态以及未保存编辑离页提示，外部文本须按纯文本显示。

#### Scenario: 窄屏查看动态
- **WHEN** 管理员在 375px 宽度下打开动态页并编辑一条草稿
- **THEN** 可阅读原话和回复、修改草稿并发送，页面不产生整体横向溢出

#### Scenario: 未保存编辑离页
- **WHEN** 管理员修改人格后切换页面但尚未保存
- **THEN** 页面提供保留编辑或明确放弃的选择，不静默丢失内容

#### Scenario: 窄屏打开设置项
- **WHEN** 管理员在 375px 宽度下打开设置页
- **THEN** 设置项列表收在抽屉里，选中一项后抽屉关闭，该项可完整操作，没有整体横向溢出

### Requirement: 设置分区折叠与摘要

设置页 MUST 以左栏列出全部设置项，按运行（运行与发送、模型、定时任务、消息分级与过滤）、数据（记忆、计费）、浏览器与采集（浏览器接管、采集来源）、排查（健康与日报、日志阶段与队列、任务执行历史）分组；每项右侧显示当前值摘要，并随状态刷新。点击一项后主区只显示该项，地址随之变化。运行模式 MUST 在“运行与发送”项中切换，选中即保存，左栏该项显示当前模式和运行状态。每项独立保存，保存不得隐式恢复处理或发送消息；有未保存修改时切换到其他项、其他页面或离开，MUST 先让管理员选择保留编辑或放弃。

#### Scenario: 浏览设置页
- **WHEN** 管理员打开设置页
- **THEN** 左栏显示四组设置项及摘要，例如使用中的模型名称、定时任务开启数量、今日估算费用、健康需关注项数；主区显示最近一次打开的设置项，首次打开时显示“运行与发送”

#### Scenario: 切换运行模式
- **WHEN** 系统暂停时管理员在“运行与发送”项把运行模式从草稿切换为自动
- **THEN** 系统保存新模式并保持暂停，左栏该项摘要显示新模式

#### Scenario: 有未保存修改时切换设置项
- **WHEN** 管理员修改了发送限制但未保存，在左栏点击“模型”
- **THEN** 页面询问保留编辑还是放弃；选择保留时停留在“运行与发送”，修改内容不变

## ADDED Requirements

### Requirement: 并入页面与分区的称呼对应

原记忆页、计费页的功能 MUST 原样作为设置页“记忆”“计费”项提供，数据、接口和交互规则不变。既有规格中的称呼按下表理解，各规格的行为要求不因页面位置改变而改变：

| 既有称呼 | 现在指 |
| --- | --- |
| “记忆页” | 设置页“记忆”项 |
| “计费页” | 设置页“计费”项 |
| “设置页某分区” | 设置页左栏中的同名设置项；“记忆策略”分区指“记忆”项的“策略”视图，“发送限制”与“运行模式”指“运行与发送”项 |
| “排查问题区” | 排查分组中的设置项 |
| “展开某分区” | 打开对应设置项 |

#### Scenario: 从动态跳到记忆
- **WHEN** 管理员点击一条私信条目的“记忆”入口
- **THEN** 设置页“记忆”项打开，并选中该条所属账号、用户的私信身份，不显示其公开身份的记忆

#### Scenario: 计费费用一致
- **WHEN** 管理员在动态条目详情中查看一条回复的费用，再打开设置页“计费”项的调用流水
- **THEN** 两处显示的是同一条原调用流水，金额一致

#### Scenario: 记忆策略的位置
- **WHEN** 管理员要修改近期互动数量
- **THEN** 在设置页“记忆”项的“策略”视图中修改并保存，保存后下一轮生效，不恢复业务
