# 面板统一设计增量规格（设置页改版）

## ADDED Requirements

### Requirement: 主区二级列表

需要先在一组对象中选中一个再查看或编辑的页面（例如设置页的“模型”选服务商、“记忆”选身份），MUST 在主区左侧显示二级列表，右侧显示选中对象的详情；二级列表与左栏使用相同的列表项样式，并带搜索或筛选。切换二级列表中的对象时，如果详情有未保存修改，MUST 先让管理员选择保留编辑或放弃。宽度不超过 860px 时，二级列表 MUST 收为详情顶部的选择器，页面不得横向溢出。

#### Scenario: 模型服务商列表
- **WHEN** 管理员打开设置页“模型”项，已添加 DeepSeek 和一个自定义中转站，使用中模型属于 DeepSeek
- **THEN** 主区左侧二级列表显示两个服务商及各自状态，DeepSeek 带“使用中”标记，右侧默认显示 DeepSeek 详情

#### Scenario: 窄屏切换记忆身份
- **WHEN** 管理员在 375px 宽度下打开“记忆”项
- **THEN** 身份以详情顶部的选择器切换，详情可完整操作，没有整体横向溢出
