# 设置页改版实施任务

当前完成 0/16 项。规格见 [panel-navigation](specs/panel-navigation/spec.md) 和 [panel-design-system](specs/panel-design-system/spec.md)，实现边界见 [design.md](design.md)，版式见 [panel-redesign-mockup.html](../add-persona-workspace/panel-redesign-mockup.html) 的设置页。

执行约束：

- 前置条件：`add-persona-workspace` 的统一设计部分（任务 1.1–1.3）已经完成，并通过服务器验收。
- 构建、自动化测试和界面验收只在服务器隔离环境执行，不使用生产数据目录。
- 生产发布需要另行授权。

## 1. 导航与外壳

- [ ] 1.1 三项导航与旧地址跳转（design.md 第 1 节）。验收：服务器界面验收覆盖：
  - 导航恰好三项，“动态”入口的待处理数量正常；
  - 全部旧地址和 `#/settings/limits` 跳转正确；
  - `#/memory?...` 跳转后选中正确的账号、身份和渠道；
  - `#/settings` 打开最近一次的设置项，首次打开为“运行与发送”。
- [ ] 1.2 设置工作区与左栏（第 2 节）。验收：
  - 四组十一项；切换项时卸载上一个模块；
  - 地址随项变化；
  - 左栏可收起并在刷新后保持；
  - 860px 以下为抽屉，选中后自动关闭。
- [ ] 1.3 左栏摘要（第 2.1 节）。验收：服务器测试和界面验收覆盖：
  - 各项摘要的文字与颜色；
  - 状态事件和保存后刷新；
  - 单个接口失败时显示“—”且其他项正常；
  - 打开设置页时模型调用计数为零，除全局状态轮询的 `/identity` 外没有浏览器请求；采集来源只在打开该项后读取。
- [ ] 1.4 未保存保护（第 2 节）。验收：在运行与发送、模型、分级、记忆、健康配置中各做一次未保存修改，切换项、切换页面和刷新页面时都会询问；选择保留时内容不变。

## 2. 设置项

- [ ] 2.1 运行与发送（第 3.1 节）。验收：
  - 运行模式选中即保存，失败时恢复原选择；暂停时切换不会恢复业务；切换模式不会提交未保存的发送限制；
  - 发送限制保存与校验同改版前；已用量显示正确；
  - “重新读取”只在点击时访问浏览器。
- [ ] 2.2 模型（第 3.2 节）。验收：模型库现有测试和界面验收全部通过（包括“添加服务商”对话框）；二级列表、搜索、使用中标记，以及窄屏下的服务商选择器正常；“可添加”条目打开预选好的对话框，已配置的内置服务商不出现在其中。
- [ ] 2.3 定时任务与任务执行历史（第 3.3、3.11 节）。验收：
  - 九个任务齐全；计划保存、单次执行（计费标记）同改版前；
  - 主循环只能改间隔，保存请求不含 `enabled`，业务保持暂停；宿主健康检查只读；
  - 执行历史可展开详情，费用与调用流水一致。
- [ ] 2.4 消息分级与过滤（第 3.4 节）。验收：指标卡数字与现有分级摘要接口一致；规则保存与校验同改版前；冷却可清除。
- [ ] 2.5 记忆（第 3.5 节）。验收：记忆相关的现有测试和界面验收通过，覆盖：
  - 三个视图；身份筛选；
  - 编辑、删除、遗忘、恢复、召回预览、立即整理；
  - 角色经历登记与隐藏；策略保存后下一轮生效；
  - 窄屏下的身份选择器。
- [ ] 2.6 计费（第 3.6 节）。验收：范围控件与现状相同（页头“近 7 日／近 30 日”，默认近 7 日，其余在更多筛选）；计费汇总、热力图三种视图、趋势、用量占比、调用流水与现有规格一致；计费图表交互验收脚本改到新位置后全部通过；“试聊”用途正常显示。
- [ ] 2.7 浏览器接管与采集来源（第 3.7、3.8 节）。验收：
  - 接管、连接、释放的语义和现有接管测试一致，左栏摘要随状态变化；
  - 桌面已连接时切到其他设置项再切回，连接不断开；
  - 采集来源列表与接口一致。
- [ ] 2.8 健康与日报、日志阶段与队列（第 3.9、3.10 节）。验收：
  - 健康指标、账号检查、日报与配置保存同改版前；
  - 日志筛选与暂停实时可用；阶段和队列内容同改版前。
