# 设置页改版：一项一页，并入记忆与计费提案

## Why

面板改版的第二份提案。第一份 [`add-persona-workspace`](../add-persona-workspace/proposal.md) 定下了统一设计：左栏列表加主区，按需带右栏，铺满视口，左右栏可收起，窄屏用抽屉。人设页已经用上这套设计。管理员希望设置页也改成同一套排版：左栏每一项就是一个设置页，点哪一项，主区就只显示哪一项；记忆和计费也并入设置。每个设置项的页面布局都重新规划。

**现状（2026-10-28 核对本机提交 `6e20f56`）：**

- 顶部导航有动态、人设、记忆、设置、计费五项。
- 设置页是一张长页，从上到下依次是：
  - 顶部一行“运行模式”下拉；
  - 模型、定时任务、发送限制、消息分级与过滤、记忆策略五个折叠分区；
  - 一个“排查问题”折叠区，里面再折叠浏览器接管、健康与日报、采集来源、运行日志阶段与队列、任务执行历史五个分区。

  分区展开状态记在浏览器中，地址 `#/settings/<分区>` 会展开并滚动到对应分区。
- 记忆页和计费页是独立的一级页面。动态条目的“记忆”入口跳到 `#/memory?...` 并选中用户。
- 旧地址 `#/overview`、`#/model`、`#/program`、`#/tasks`、`#/browser` 已跳转到动态页或设置页对应分区。

## What Changes

- **顶部导航改为三项**：动态、人设、设置。
  - 旧地址 `#/memory`（包括查询参数）跳到设置页“记忆”项并保留选中；`#/billing` 跳到设置页“计费”项；
  - 原有的旧地址跳转改为指向对应的新设置项；
  - “动态”入口上的待处理数量不变。
- **设置页改为工作区，左栏一项一页**：

  | 分组 | 设置项 |
  | --- | --- |
  | 运行 | 运行与发送、模型、定时任务、消息分级与过滤 |
  | 数据 | 记忆、计费 |
  | 浏览器与采集 | 浏览器接管、采集来源 |
  | 排查 | 健康与日报、日志阶段与队列、任务执行历史 |

  - 每项右侧显示当前值摘要，例如“自动 · 已暂停”“GLM-4.6”“2 / 4 启用”“今日 $0.42”“需关注 2”，并随状态刷新；
  - 主区页头放该项名称、说明和保存等操作，主区内容一次只显示一项；
  - 设置页只有左栏和主区两栏，没有右栏。
- **每个设置项的新布局**（草图见 [panel-redesign-mockup.html](../add-persona-workspace/panel-redesign-mockup.html) 的设置页）：
  - **运行与发送**：运行模式改为两张单选卡，选中即保存；发送限制是带“本小时已用”的数字框，需要点保存；账号字数用列表展示，带“重新读取”。原来顶部的运行模式下拉移到这里。
  - **模型**：主区内左侧是服务商二级列表，分已配置和可添加两组；右侧是接口、模型选择和参数；页头放刷新目录、连接测试（计费）和保存。
  - **定时任务**：与现在一样列出九个任务，每个一行，含开关、名称、计划时间、上次结果和“单次执行”（会调用模型的带计费标记）；主循环只能改间隔、不给开关，宿主健康检查只读；底部链接到任务执行历史。
  - **消息分级与过滤**：顶部四个数字（今日公开额度、排队、今日过滤、骚扰冷却），下面是规则表单和冷却名单，冷却可以清除。
  - **记忆**：原记忆页并入。主区内左侧是身份二级列表（搜索、全部／公开／私信），右侧是选中身份的长期记忆、近期往来和操作。页头切换“用户记忆／角色经历／策略”三个视图，原设置页的“记忆策略”分区并入“策略”视图。
  - **计费**：原计费页并入，汇总条、热力图、趋势、用量占比、调用流水的内容、范围控件和交互都保持现有规格，只是改用新设计的样式。
  - **浏览器接管**：上方是账号与接管状态列表，下方是桌面区域；接管、连接、释放都在本项完成。
  - **采集来源**：每个来源一行，显示启用状态和原因。
  - **健康与日报**：顶部指标卡，下面依次是账号检查、日报列表；健康与披露配置默认收起。
  - **日志阶段与队列**：页头切换“日志／阶段／队列”，日志带筛选和暂停实时。
  - **任务执行历史**：每次执行一行，显示状态、耗时和费用，可展开详情。
- **保存与离开**：
  - 每项独立保存，保存不会恢复业务或发送消息；
  - 切换到其他设置项、其他页面或离开时，有未保存修改要先确认；
  - 收起左栏、窄屏抽屉等行为沿用统一设计。
- **统一设计补充**：新增“主区二级列表”规则，用于模型和记忆这类要先选一项再编辑的设置项。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `panel-navigation`：
  - 修改“一级页面导航”“主题与窄屏可用性”“设置分区折叠与摘要”（来自未归档的 `simplify-panel-activity-feed`）；
  - 修改“浏览器人工接管”（来自未归档的 `separate-run-control-from-takeover`）；
  - 修改“页面职责和同源设置”（以 `add-persona-workspace` 中的版本为准）；
  - 新增“并入页面与分区的称呼对应”：说明既有规格中“记忆页”“计费页”“设置页某分区”“排查问题区”现在分别指哪个设置项，从而不逐条改写这些规格。
- `panel-design-system`：新增“主区二级列表”（该能力来自未归档的 `add-persona-workspace`）。

本提案排在 `add-persona-workspace`、`simplify-panel-activity-feed`、`separate-run-control-from-takeover` 之后归档；`redesign-feed-workspace` 排在本提案之后。

## Impact

- **前端**：
  - `public/js/app.js`：三项导航、旧地址跳转；
  - `public/js/views/settings.js`：重写为设置工作区，各设置项拆成独立模块，复用 `model.js`、`task-settings.js`、`triage-settings.js`、`browser.js`、`program.js` 中的逻辑；
  - `memory.js`、`billing.js`：改为在设置项中挂载，去掉页面级标题和布局；
  - `public/style.css`：只增加新设计的样式，不改仍在旧版式中的动态页。
- **后端**：不改任何设置的含义、默认值、校验和保存接口。左栏摘要优先复用现有接口；如果打开设置页时请求过多，可以新增一个只读的摘要接口（实施者决定，见 design.md）。
- **测试**：
  - 新增设置工作区界面验收；
  - 改写五页、计费图表、模型库、记忆等现有界面验收脚本中与页面位置相关的步骤；
  - 各设置的保存与校验行为测试保持通过。
- **文档**：`docs/前端接口.md`、`docs/后续提案实施.md`（五页说明改为三页）、README 页面表、`docs/设计规范.md`（二级列表）。
- **不涉及**：
  - 不改任何设置的含义、范围、默认值和生效时机；
  - 不改模型库、记忆、计费、健康、日志的数据与接口语义；
  - 不改人设页；
  - 动态页的改版由 `redesign-feed-workspace` 负责。
- **回退**：只有前端变化，回退到旧版本即恢复五页导航和长设置页；浏览器里记住的收起状态对旧版本无影响。
- 本次只创建规划文件。构建和测试在服务器隔离环境执行；生产发布需要另行授权。

## Out of Scope

- 改变任何设置项的功能、字段或校验。
- 动态页改版。
- 计费图表的统计口径和交互规则（沿用 `add-billing-chart-interaction` 及计费现有规格）。
- 合并或拆分已有的接口。
