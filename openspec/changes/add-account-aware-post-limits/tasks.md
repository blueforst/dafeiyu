# 账号发帖长度策略实施任务

本轮已完成保守短帖策略、互斥能力读取、持久预检及回复／任务出站收束的隔离实现。服务器类型检查、构建及最近一轮全量 **325/325** 回归通过，其中字数策略 **9/9**、草稿流程 **14/14**、缓存生命周期与试聊策略 **7/7**；五页界面脚本 **12/12** 通过。总证据、执行位置与真实验收边界见[六项后续提案实施记录](../../../docs/实施记录/2026-10-28-后续提案.md)，实现及恢复契约见[账号发帖限制](../../../docs/账号发帖限制.md)。规格见 [x-posting-limits](specs/x-posting-limits/spec.md)，实现边界见 [design.md](design.md)。

以下仅勾选本轮已有完整隔离验收覆盖的任务。任务中混有未完成长帖或专项页面／恢复要求时整项保持未完成；短帖回退、一般界面验收或格式校验不能代替该要求。真实权限读取、编辑器验证和实际发送分别记录，本轮不授权生产发布或发帖。

## 1. 平台证据与计数适配

- [ ] 1.1 采集当前账号及已有可用样本中与原创／回复能力有关的脱敏页面或原生响应，记录账号绑定、来源、上限与无法确认的情况；以证据文档及未知时回退规则可复核为验收，不点击发送探测权限。
- [ ] 1.2 在服务器隔离浏览器验证短帖和长帖计数适配，覆盖 ASCII、汉字、emoji、ZWJ、组合字符、NFC 及已确认上限前后；以保存的样本和可重复回归通过为验收，未确认的适配器不得授权长帖。
- [ ] 1.3 取得或整理完整长帖、长回复及截断预览样本，记录可靠正文和回复关系来源；以服务器解析回归能区分完整文本、前缀和同文错误目标为验收，并将已知平台限制写入说明。

## 2. 共用策略与账号能力

- [ ] 2.1 实现共享长度策略、公开资源保护与渠道分离，验证 280 加权字符边界、已确认长帖边界、未知计数回退及私信 4,000 规则；以服务器定向测试通过为验收，保留现有禁用内容检查。
- [x] 2.2 实现按账号、操作类型、浏览器会话和修订保存的能力快照及十五分钟有效期；以服务器可控时钟测试验证过期、重启、切号、退出、接管释放及证据冲突均不能继承旧长帖权限。
- [x] 2.3 实现受鉴权的限制读取和显式刷新，沿用工作流与浏览器互斥；以服务器接口测试验证 GET 无页面副作用、暂停不恢复、人工接管返回明确冲突、外部自报上限无效。

## 3. 生成、草稿与持久出站

- [x] 3.1 将原创和回复限制注入共用生成提示词，接入正常工作流及早晚安任务；以服务器集成测试验证所用策略正确、无额外模型请求、4096 token 默认和 OpenCode 会话路由不变。
- [x] 3.2 将结构解析与长度判定分开，接入公开试聊并保留私信规则；以服务器测试验证无账号时显式普通模拟、有账号时使用对应缓存、试聊不写真实出站及计费记录保留。
- [x] 3.3 为出站新增可空校验元数据及可重复迁移，保存有界超长草稿并限制 begin；以服务器旧库／重复迁移／直接出站入口测试验证未校验草稿不能提交、费用不丢失、无自动截断或生成重试。
- [x] 3.4 更新出站、模型提示词与草稿失败说明，并同步未归档七页提案中公开加权校验条款为短帖／长帖分规则；以规格无冲突、受鉴权详情能追溯计数与修订、普通日志无正文为验收，不变更旧提案未完成验收状态。

## 4. 浏览器提交与回执收束

- [ ] 4.1 在原创／公开回复的最终提交边界接入浏览器独立校验，复核当前账号、能力和编辑器状态；以服务器 DOM 测试验证权限降级、缓存失效、伪造上限和切号均不能点击提交。
- [x] 4.2 实现确定未提交结果、独立版本化预检持久记录和同标识回查；以服务器故障注入验证响应丢失、写盘失败、重启及重复请求不会自动发送，未对账记录不被清理丢失。
- [x] 4.3 接入回复、任务、outbox 和回查对未提交结果的收束；以服务器集成测试验证 cancelled 不计小时额度、不启动四小时冷却，真正 rejected 和不明确异常继续沿用原行为。
- [ ] 4.4 接入完整长帖正文与回执匹配，确保旧 unknown 优先回查而非重新校验新发送长度；以服务器回归验证降权后可回查、截断前缀不确认、原创／回复关系及唯一 ID 不误匹配。
- [x] 4.5 更新浏览器结果契约、日志保留和恢复文档；以服务器端消费者类型检查及覆盖全部结果分支的测试通过为验收，明确提交意图保存后不得报告为安全未提交。
