# 人设预设与默认人设实施任务

当前完成 12/15 项代码与隔离验收；v2 口吻与“被夸”卡、服务器全量 508/508、预设界面 13/13 及含 240 条预览的模拟全链 6/6 均通过。真实模型计费批量、管理员审定和生产发布三项保持未完成；模拟结果不代替审定。规格见 [persona-management](specs/persona-management/spec.md)，实现边界见 [design.md](design.md)。构建、测试和界面验收只在服务器隔离环境执行，不使用生产 profile；真实模型批量验收和生产发布需要另行授权。本提案依赖 `fill-reference-post-gaps` 的关键词卡片：那部分代码提交后再开始实施，并且必须在它发布之后发布。

## 2026-10-28 发布与调用顺序

用户明确要求先部署、部署后进行计费模型调用，已按该顺序发布 v2；没有据此补勾真实试聊、全部回复审阅或条件未齐的发布任务。随后用户要求“全部修好后再进行模型调用”，当前新增真实调用为零，先修复并实机复验采集与账号检查问题。模型调用授权已经取得，未执行原因是修复前置条件，不再重复请求相同授权。实际版本和验收见[发布与实机修复记录](../../../docs/实施记录/2026-10-28-发布与实机修复.md)。

- [x] 3.2 保存来自预设的人设后，在当前页面显示提示框，直到关闭或离开页面（来源只记在前端内存）：今日日程不会自动改变；角色预设额外提醒修改 X 名称和简介、建议把“非官方”加入披露词，并附到设置页的链接。验收：Camoufox 验收确认角色预设和通用默认的提示内容不同，且保存前后合规检查设置不变。
