## 2. 分级、过滤与合并

- [x] 2.1 新增 `src/reply-triage.ts` 分级规则及面板 `triage` 设置（词表、阈值、普通时效、重点名单）；以服务器单元测试覆盖规格中重点账号、新人招呼、老面孔招呼、老朋友、首次来访、提问各场景为验收。
- [x] 2.2 实现广告与批量刷量过滤；以服务器测试验证三个账号同文触发、短文本不参与、仅含链接不被过滤、被过滤消息不产生模型调用为验收。
- [x] 2.3 实现同会话三十分钟内公开消息合并与跨会话降级，合并条目进入生成上下文；以服务器集成测试验证只发送一条回复、其余为 `merged` 且指向该回复为验收。

## 3. 出队与额度

- [x] 3.1 实现按通道可用性出队、级别排序与分级时效，超时条目不占名额并限制每轮检查条数；以服务器集成测试验证公开额度满时处理私信、两通道都不可用时不生成也不置失败为验收。
