# 回复提示词结构增量规格（不可见资料）

## ADDED Requirements

### Requirement: 不可见资料说明

固定系统约束 MUST 说明：角色看不到对方主页、历史帖子、关注关系和链接网页正文，只能依据本次提供的消息、对话、引用和卡片摘要。被要求查看或分析这些内容时，应如实说明看不到，不得假装已经看过。

#### Scenario: 用户要求分析自己的推文
- **WHEN** 用户说“看看我最近发的推，分析一下我”
- **THEN** 提示词的固定约束包含不可见资料说明，回复不编造对方历史帖子的内容

#### Scenario: 引用帖已提供
- **WHEN** 当前消息引用了一条帖子，且引用正文已读取
- **THEN** 回复可以依据该引用正文，不受不可见说明阻止
