# 对话记忆增量规格（角色经历）

## ADDED Requirements

### Requirement: 角色经历召回范围

回复生成时的角色经历 MUST 只包含当前工作账号已确认的角色发帖和可用的人工登记经历，按发生时间取最近十条，不得包含与其他用户的普通回复。与当前用户的往来继续由近期互动上下文提供。回复确认后的互动记录仍然保留，供记忆页和审计使用，但不作为角色经历召回。

#### Scenario: 早安帖后发出大量回复
- **WHEN** 早安帖确认发布后，又向不同用户确认发送了五十条公开回复
- **THEN** 之后生成回复时，角色经历中仍能看到早安帖

#### Scenario: 回复过其他用户
- **WHEN** 角色刚公开回复了用户甲，随后为用户乙生成回复
- **THEN** 用户乙的提示词中，角色经历不包含给用户甲的回复

#### Scenario: 连续回复期间经历段稳定
- **WHEN** 两次生成之间只发生了普通回复，没有新的发帖或经历变更
- **THEN** 两次提示词的角色经历部分完全相同

### Requirement: 人工登记角色经历

管理员 MUST 能在记忆页查看当前工作账号的角色经历，并登记、编辑、隐藏人工经历（正文、发生日期、可选的当前账号帖子链接）。没有链接的人工经历可以直接使用。带链接的人工经历要等系统在浏览器空闲的下一轮只读核对、确认该帖属于当前账号后才使用；核对失败时不使用，并显示原因。人工经历与自动记录分开标注，只在当前工作账号下使用，不得写成任何用户的事实。被隐藏的经历（含自动记录的发帖）不再进入提示词，平台回执和出站记录不受影响。

#### Scenario: 登记人工接管期间发的帖子
- **WHEN** 管理员在人工接管时发了一条版本更新帖，随后附上链接登记为角色经历
- **THEN** 核对通过后，该经历标记为已核对，并出现在后续回复的角色经历中

#### Scenario: 链接不属于当前账号
- **WHEN** 登记的链接作者不是当前工作账号
- **THEN** 核对失败并显示原因，该经历不进入提示词

#### Scenario: 隐藏一条自动记录的发帖
- **WHEN** 管理员隐藏一条已确认的早安帖经历
- **THEN** 后续提示词不再包含它，平台回执与出站记录不变
