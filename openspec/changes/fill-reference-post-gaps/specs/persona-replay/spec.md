# 人设回放增量规格（模型设置对比）

## ADDED Requirements

### Requirement: 模型设置对比

回放 MUST 支持以模型设置为比较对象：两侧使用同一份已保存人设和提醒设置；基线用使用中的模型重新生成，候选用管理员从模型库选择的模型与推理档位。每条样本只执行一次语义判定，两侧共用其结果。预估 MUST 按两侧各自模型的 Pi 价格分别计算，未定价的一侧如实显示。结果 MUST 分别展示两侧的平均耗时、输入和输出 token、缓存读取与实际费用。模型对比不改变使用中的模型，也不提供一键采用。

#### Scenario: 比较开启思考前后
- **WHEN** 管理员选择同一模型、候选推理档位设为 low，对 16 条公开样本运行回放
- **THEN** 结果并排展示两侧回复，并列出两侧的平均耗时、输出 token 与费用差异

#### Scenario: 候选模型未定价
- **WHEN** 候选模型没有可靠的 Pi 价格
- **THEN** 预估显示候选侧未定价、基线侧按价格估算，确认前不会显示为免费

#### Scenario: 语义规则只判定一次
- **WHEN** 人设启用了语义触发规则
- **THEN** 每条样本只产生一次语义判定请求，两侧注入相同的命中规则

#### Scenario: 对比结束后
- **WHEN** 模型对比回放完成
- **THEN** 使用中的模型保持不变，结果页只提供前往模型设置的入口
