# 消息分级增量规格（回复时段）

## MODIFIED Requirements

### Requirement: 出队顺序与分级时效

系统 MUST 按级别优先、同级内平台时间较新者优先的顺序出队；普通消息超过普通时效（默认三小时）、优先消息超过现有处理时效（默认六小时）时记录为超时跳过，不再生成。等待时长 MUST 扣除回复时段关闭的时长。

#### Scenario: 优先与普通同时排队
- **WHEN** 队列中有一条较早的优先消息和一条较新的普通消息
- **THEN** 系统先处理优先消息

#### Scenario: 普通闲聊等待过久
- **WHEN** 一条普通消息已等待三个半小时
- **THEN** 系统记录超时跳过；同样等待时长的优先消息仍会处理

#### Scenario: 跨夜等待
- **WHEN** 一条普通消息 23:10 入队，回复在 23:30 至 08:00 关闭，现在是 08:30
- **THEN** 等待时长计为 50 分钟，消息仍会处理
