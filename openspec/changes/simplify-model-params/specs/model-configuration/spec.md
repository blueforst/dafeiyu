# 模型配置增量规格（模型参数精简）

## MODIFIED Requirements

### Requirement: 请求额度与未知价格

正式回复请求的输出上限 MUST 取所选模型自身允许的最大输出；目录中识别不到的模型按 8192 token。“输入加最大输出”可能超过模型上下文长度时，系统 MUST 自动收小输出上限，使请求不超过上下文长度。回复的实际长度 MUST 只由当前 X 账号的发帖限制约束，不得再有用户可设的 token 上限。连接测试和内部任务 MUST 继续使用各自较小的固定上限。CommandCode 缺少价格时不得显示为免费。

#### Scenario: 新建模型配置
- **WHEN** 管理员创建模型设置
- **THEN** 模型参数只有推理强度，没有默认 4096 token 的回复上限；正式回复按模型自身最大输出请求，连接测试不按此上限请求长篇输出

#### Scenario: 使用目录中的模型
- **WHEN** 使用中的模型在目录中的最大输出为 32768 token，系统生成一条公开回复
- **THEN** 请求的输出上限为 32768 token，回复长度按当前账号的发帖限制校验

#### Scenario: 上下文接近用满
- **WHEN** 一次请求的输入较长，加上模型最大输出会超过上下文长度
- **THEN** 系统收小本次的输出上限，请求不因超过上下文长度被接口拒绝

#### Scenario: 连接测试
- **WHEN** 管理员测试一个模型
- **THEN** 测试请求仍使用较小的固定上限，不按模型最大输出请求

#### Scenario: CommandCode 没有价格
- **WHEN** 页面展示没有可靠价格的 CommandCode 模型
- **THEN** 页面标记价格未提供而不套用原厂价格

### Requirement: 服务商模型列表

服务商详情 MUST 以可搜索列表显示该服务商的模型，管理员测试过、编辑过或正在使用的模型排在前面。每行显示模型名称、上下文长度、推理与看图标记，并提供测试、编辑和设为使用中。编辑 MUST 只包含推理强度；无法识别的模型另需填写上下文长度和是否支持推理。编辑窗口 MUST NOT 提供回复长度上限或超时。

#### Scenario: 在长列表中选择
- **WHEN** 某服务商拉取到上百个模型
- **THEN** 管理员可按名称搜索，已用过的模型显示在顶部

#### Scenario: 选择未识别的模型
- **WHEN** 管理员把一个目录无法识别参数的模型设为使用中或打开编辑
- **THEN** 编辑窗口要求填写上下文长度和是否支持推理后才能保存

#### Scenario: 编辑已识别的模型
- **WHEN** 管理员打开一个目录中已识别模型的编辑窗口
- **THEN** 窗口只有推理强度一项，没有回复长度上限和超时

### Requirement: 既有模型配置迁移

升级后系统 MUST 把原有的单一模型配置迁移为一个已添加服务商及其中一个使用中模型，保留地址、协议、推理强度、自定义参数和已保存的 Key。已保存的回复长度上限和超时（包括配置文件中的同名字段）MUST 照常读取但不再生效，下次保存时移除；接口收到这两个字段时 MUST 忽略而不报错。

#### Scenario: 升级后打开模型分区
- **WHEN** 升级前已配置并测试过一个 OpenCode 模型
- **THEN** 升级后模型分区左栏显示 OpenCode 并标记使用中，推理强度、Key 掩码和测试结果与升级前一致，正式请求仍保留会话路由

#### Scenario: 旧参数不再生效
- **WHEN** 升级前某模型的回复长度上限保存为 1024、超时为 30 秒
- **THEN** 升级后该模型的正式请求按模型最大输出和固定保护时限发送，编辑窗口不显示这两项；管理员再次保存参数后，设置中不再有这两个字段

## ADDED Requirements

### Requirement: 模型请求保护时限

每次模型请求 MUST 使用固定的 180 秒保护时限，超过即中止，按超时失败记录，已返回的用量照常落账。该时限 MUST NOT 在页面显示或允许配置。整轮处理仍受无人值守健康的软、硬超时约束，硬超时到达时立即中止正在进行的请求。

#### Scenario: 接口卡住
- **WHEN** 一次回复请求 180 秒内没有完成
- **THEN** 请求被中止，本条按超时失败处理，调用流水记录失败状态

#### Scenario: 轮次硬超时先到
- **WHEN** 整轮处理的硬超时早于单次请求的 180 秒到达
- **THEN** 正在进行的请求立即中止，不等满 180 秒
