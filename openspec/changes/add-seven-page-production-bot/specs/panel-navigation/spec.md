# 七页面板导航增量规格

## MODIFIED Requirements

### Requirement: 一级页面导航

管理面板 MUST 恰好提供主页面、模型页、人设页、记忆页、主程序页、定时任务页、计费页七个一级页面，默认打开主页面；浏览器接管并入主页面，旧浏览器地址保持兼容。

#### Scenario: 默认进入概览
- **WHEN** 管理员打开未指定页面的面板地址
- **THEN** 系统显示主页面，导航恰好包含七个约定页面

#### Scenario: 页面地址直接访问
- **WHEN** 管理员访问 `#/model` 或 `#/browser`
- **THEN** 模型地址仍打开模型页，旧浏览器地址跳转主页面并展开接管区

#### Scenario: 直接访问新增页面
- **WHEN** 管理员打开 `#/persona`、`#/memory`、`#/program`、`#/tasks` 或 `#/billing`
- **THEN** 系统打开对应页面，不要求先经过主页面

### Requirement: 全局控制与配置保存

管理面板 MUST 展示暂停、处理中、等待排空和人工接管状态；保存任何页面的配置不得隐式恢复处理或发送消息，配置应在约定的后续轮次或任务执行中生效。

#### Scenario: 暂停时保存模型
- **WHEN** 系统处于暂停状态且管理员保存有效模型配置
- **THEN** 系统仍保持暂停，配置用于后续显式恢复后的处理

#### Scenario: 保存人设或任务设置
- **WHEN** 系统暂停且管理员保存人设、记忆策略或任务计划
- **THEN** 系统不因保存而恢复或发帖

### Requirement: 浏览器人工接管

系统 MUST 在主页面提供浏览器人工接管，排空自动操作并进入接管后才允许桌面连接；释放接管必须断开交互连接并保持暂停。

#### Scenario: 非接管状态连接桌面
- **WHEN** 管理员在非人工接管状态访问桌面入口
- **THEN** 系统拒绝连接并提示先接管

#### Scenario: 释放人工接管
- **WHEN** 管理员释放已连接的人工接管
- **THEN** 浏览器交互连接断开，自动处理不恢复

## ADDED Requirements

### Requirement: 页面职责和同源设置

系统 MUST 在人设页管理日程内容、在任务页管理生成计划，两处共享同一有效设置和结果；模型、记忆、程序和计费内容按七页职责提供独立入口。

主页面 MUST 不再重复显示日志区；主程序页 MUST 集中展示原主页面的行式日志，包含时间、事件和说明，并保留该页的筛选及暂停实时能力。

#### Scenario: 查看主程序日志
- **WHEN** 管理员从主页面进入主程序页
- **THEN** 主页面没有日志区，主程序页提供原主页面样式的日志列表，不再并列显示两份不同的日志组件

#### Scenario: 调整日程生成时间
- **WHEN** 管理员在任务页保存新的生成时间
- **THEN** 人设页显示同一时间，不出现第二份可冲突的调度配置

### Requirement: 主题与窄屏可用性

七个页面 MUST 支持系统浅色／深色、375px 宽度、加载／空数据／错误状态以及未保存编辑离页提示，外部文本须按纯文本显示。

#### Scenario: 窄屏查看主程序
- **WHEN** 管理员在 375px 宽度下打开主程序页
- **THEN** 可读取阶段、日志并进行必要操作，页面不产生整体横向溢出

#### Scenario: 未保存编辑离页
- **WHEN** 管理员修改人格后切换页面但尚未保存
- **THEN** 页面提供保留编辑或明确放弃的选择，不静默丢失内容
