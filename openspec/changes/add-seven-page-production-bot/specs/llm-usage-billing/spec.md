# LLM 用量与计费增量规格

## Purpose

为回复、触发判定、虚构日程、记忆整理和其他模型用途提供一致且可追溯的调用记录，让管理员区分实际返回的用量、可估算费用与未知信息。计费页仅提供成本估算，不承担充值、收款或服务商账户余额功能。

## ADDED Requirements

### Requirement: 全用途请求计量

系统 MUST 为回复、语义触发、日程、记忆、连接测试、CLI 测试、试聊、早安及晚安的每次实际模型请求记录唯一调用、用途、来源、模型、状态和耗时；重试必须保留新的实际请求。

#### Scenario: 一轮试聊包含语义判断与生成
- **WHEN** 管理员发起一轮需要触发判定的试聊
- **THEN** 系统记录两次独立调用，并在试聊显示两者合计费用

#### Scenario: 同一消息重新请求模型
- **WHEN** 第一次生成失败后发起新的真实请求
- **THEN** 系统保留两次调用，不能按消息 ID 覆盖首次消耗

### Requirement: 完整 token 与思考子集

系统 MUST 保留返回的输入、输出、缓存读取、缓存写入、总 token 及可用的思考拆分；思考属于输出子集，不得再次增加输出或总费用。

#### Scenario: 输出包含思考 token
- **WHEN** 模型返回输出一百 token，其中思考六十 token
- **THEN** 计量输出仍为一百，不以一百六十计算

### Requirement: 失败和中止用量

系统 MUST 保存错误、中止或后续输出校验失败时已经返回的用量；未获得用量或费用时显示未知，进程中断的请求不得冒充已完成或免费。

#### Scenario: 返回部分用量后中止
- **WHEN** 请求在生成期间中止且服务商返回部分 usage
- **THEN** 流水显示中止状态及该部分实际用量和可估算费用

#### Scenario: 没有用量返回
- **WHEN** 请求异常结束且没有可靠 usage
- **THEN** 页面显示用量或费用未知，不声称消费为零

### Requirement: Pi 内置价格边界

系统 MUST 只对可靠匹配 Pi 内置服务商及模型价格的请求计算估算，复用缓存和分档计价；未知型号、CommandCode 及自定义中转站不能因同名而套用原厂或兜底模型价格。

#### Scenario: 中转站与原厂模型同名
- **WHEN** 自定义接口返回一个 Pi 已知模型名称但没有可靠中转站价格
- **THEN** 系统统计 token 并标记未定价，不显示为原厂价格或免费

### Requirement: 历史成本快照

系统 MUST 保存请求当时的成本结果，更改模型、价格目录或升级后不重算旧流水；旧 usage 缺少价格和模型时必须保留 token 并明确未知成本。

#### Scenario: 模型目录更新
- **WHEN** 已记录请求后目录中的参考价格变化
- **THEN** 旧请求费用不变，新请求使用当时适用的参考数据

### Requirement: 计费页汇总与流水

计费页 MUST 提供今日、本月和自选日期范围的请求数、token、美元估算及未定价数量，展示每日趋势、按模型／用途汇总及有限分页调用明细；筛选口径必须一致。

#### Scenario: 切换日期范围
- **WHEN** 管理员选择新的北京时间日期范围
- **THEN** 汇总、趋势和流水使用同一范围，金额注明 Pi 目录估算

#### Scenario: 只有未定价请求
- **WHEN** 当前范围内没有可估价调用
- **THEN** 页面明确显示未定价数量和未知费用，不把估算总额零误作全部免费

### Requirement: 流水数据最小化

计费记录 MUST 不保存提示词、回复正文或完整密钥，页面与接口沿用管理鉴权；人设页和任务页可以引用同一流水的费用，不重复记账。

#### Scenario: 从任务页查看生成费用
- **WHEN** 管理员打开某次早安任务的费用详情
- **THEN** 系统引用原调用流水，不新增费用记录或泄露请求正文与密钥
