## 1. 后端

- [x] 1.1 会话列表查询与接口（design.md 第 1、2 节）。验收：服务器单元与接口测试覆盖：
  - 身份划分；角色帖会话包含出站帖子和没有发帖的任务记录；
  - 排序按入库时间，`ingested_at` 为 0 的旧数据回退到 `created_at`；状态变化不改变顺序；
  - 私信会话的占位名称；
  - 状态标签优先级（含排队等待处理一档）；待处理复用现有判定，过期草稿不计入；总数含待核对补录，与 `ActivityFeed.summary` 一致；
  - `changedSince` 只返回变化的会话；
  - 五种筛选；键集分页在翻页过程中插入新消息时不重复不遗漏；
  - 只返回当前账号；接口不产生写入、模型调用和浏览器请求。
- [x] 1.2 会话往来查询与接口（第 2 节）。验收：
  - 条目包含现有 `/api/feed` 的全部字段，另有 `tier`、`tierReason`、`sortAt`；
  - `changedSince` 只返回变化的条目；
  - `GET /api/messages/:id` 新增的分级和人设快照字段正确，原有字段与测试不变；
  - `before` 游标翻页不重复不遗漏；
  - 公开、私信、角色帖三类会话都正确；非法 key 和游标返回 400。
- [x] 1.3 查询性能核对（第 2 节）。验收：
  - 在服务器用一万条消息的隔离数据记录会话列表的查询计划与耗时；
  - 结果写入实施记录，说明是否新增了只加索引的迁移；
  - 如果新增了迁移，按 `docs/迁移与恢复.md` 补充回退说明并测试。

## 2. 前端

- [x] 2.1 工作区与路由（第 3.1 节）。验收：
  - 三栏；四个主区视图；地址 `#/feed`、`#/feed/c/<key>`、`#/feed/attention`、`#/feed/import` 可直接打开；
  - 列表为空时显示空状态。
- [x] 2.2 左栏（第 3.2 节）。验收：
  - 筛选与待处理数；“需要关注”入口的显示、隐藏和错误色；
  - 会话列表滚动加载；底部运行状态与全局状态一致。
- [x] 2.3 会话往来与草稿操作（第 3.3 节）。验收：
  - 气泡、正文、摘要、虚线说明、日期分隔正确；
  - 批准、重写、取消、过期、修订冲突、等待原因在会话中操作的结果与改版前一致，现有草稿审核测试全部通过；
  - “重新入队”在已过滤、冷却、合并、失败、跳过条目上的可用条件与改版前一致，现有重新入队测试通过；
  - 滚动到顶部加载更早往来时位置不跳动；
  - “记忆 →”打开设置页记忆项并选中正确的身份。
- [x] 2.4 需要关注与按链接补录（第 3.3 节）。验收：
  - 告警来源和文字与改版前一致，每张卡片链接到正确的设置项或会话；
  - 补录表单与列表行为不变，现有补录测试通过。
- [x] 2.5 右栏详情与只读记忆（第 3.4 节）。验收：
  - 详情字段与费用同改版前的展开详情一致，不含提示词和密钥；
  - 只读记忆与召回预览一致；
  - 收起状态在刷新后保持，选中往来不会自动展开。
- [x] 2.6 实时刷新（第 3.5 节）。验收：
  - 编辑草稿时同一会话和其他会话各收到新消息，草稿文字和光标不变，阅读位置不跳动，左栏正确重排，非底部时出现“有新消息”提示；
  - 第三页上某个会话的状态变化能原位更新，刷新时不重读全部已加载分页（断言请求数）。
- [x] 2.7 界面总验收（第 3.6 节）。验收：
  - 1440、1280、860、375 四种宽度，浅色和深色，四个视图截图存入证据目录，无整体横向滚动；
  - 375px 下可以完成草稿编辑和发送；
  - 现有动态页界面验收脚本改写后通过。
