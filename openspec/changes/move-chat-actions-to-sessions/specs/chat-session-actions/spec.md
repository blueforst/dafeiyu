## Purpose

将人设试聊中的用户会话管理操作直接归属到左栏对应的会话选项，使管理员在选择与管理多个模拟用户时能够清楚识别目标，并在鼠标、键盘和触屏环境下可靠执行相同操作，避免误修改其他会话。

## ADDED Requirements

### Requirement: 会话行操作菜单

试聊每个会话项 MUST 提供独立的会话操作菜单，包含改名/handle、重置、清除冷却和删除；操作 MUST 绑定该项用户，打开菜单不得切换会话。主区页头 MUST 不再重复显示用户操作菜单。

#### Scenario: 管理未选中的会话
- **WHEN** 管理员打开未选中会话的菜单并执行操作
- **THEN** 仅操作该项用户，当前会话和未发送输入保留；删除与重置先确认目标

### Requirement: 键盘及触屏菜单

会话菜单 MUST 可通过键盘和触屏打开，具有明确的可访问名称，Escape 和外部点击能够关闭。窄屏菜单 MUST 完整可见且不触发会话选择或抽屉关闭。

#### Scenario: 窄屏打开并取消菜单
- **WHEN** 管理员在窄屏会话列表打开菜单后按 Escape
- **THEN** 菜单关闭、焦点回到对应入口，当前会话不变
