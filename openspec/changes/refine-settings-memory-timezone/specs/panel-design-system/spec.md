# 面板统一设计增量规格（左栏条目颜色）

## ADDED Requirements

### Requirement: 左栏条目颜色一致

所有工作区页面的左栏条目 MUST 使用正文色显示名称、弱化色显示副标题和附注，无论条目以按钮还是链接实现；工作区通用的链接颜色和悬停下划线 MUST NOT 作用于左栏条目。选中项只用选中背景区分，不改变文字颜色。浅色与深色主题都须满足。

#### Scenario: 设置项以链接实现
- **WHEN** 设置页左栏的设置项以带地址的链接实现，管理员在浅色主题下打开设置页并悬停其中一项
- **THEN** 设置项名称为正文色而不是品牌蓝，悬停只显示悬停背景，没有下划线

#### Scenario: 三页左栏对照
- **WHEN** 管理员在深色主题下依次打开动态页、人设页和设置页
- **THEN** 三页左栏条目的名称颜色、字号、行高与选中背景一致
