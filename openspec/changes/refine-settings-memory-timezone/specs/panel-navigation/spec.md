# 面板导航增量规格（设置左栏与健康页）

## MODIFIED Requirements

### Requirement: 设置分区折叠与摘要

设置页 MUST 以左栏列出全部设置项，按运行（运行与发送、模型、定时任务、消息分级与过滤）、数据（记忆、计费）、浏览器与采集（浏览器接管、采集来源）、排查（健康与日报、日志阶段与队列、任务执行历史）分组。每项只显示名称，不显示文字摘要；只有该项需要处理时，名称右侧 MUST 显示一个状态圆点，并随状态刷新。圆点 MUST 带可读名称和悬停说明，说明当前状态，例如“健康：需关注 4 项”。需要处理的情况为：健康需关注或异常、浏览器人工接管中或需要登录、最近一次任务执行失败、模型尚未配置、运行配置有错误；其余情况不显示圆点。点击一项后主区只显示该项，地址随之变化。运行模式 MUST 在“运行与发送”项中切换，选中即保存，当前模式和运行状态显示在该项页头与顶部运行控制中。每项独立保存，保存不得隐式恢复处理或发送消息；有未保存修改时切换到其他项、其他页面或离开，MUST 先让管理员选择保留编辑或放弃。

#### Scenario: 浏览设置页
- **WHEN** 管理员打开设置页，健康状态为需关注 4 项，其余各项都没有需要处理的情况
- **THEN** 左栏显示四组设置项名称，只有“健康与日报”右侧有告警色圆点，悬停或读屏读出“健康：需关注 4 项”；其他项没有圆点或摘要文字；主区显示最近一次打开的设置项，首次打开时显示“运行与发送”

#### Scenario: 切换运行模式
- **WHEN** 系统暂停时管理员在“运行与发送”项把运行模式从草稿切换为自动
- **THEN** 系统保存新模式并保持暂停，该项页头和顶部运行控制显示新模式，左栏不因模式切换出现圆点

#### Scenario: 人工接管时显示圆点
- **WHEN** 浏览器进入人工接管
- **THEN** 左栏“浏览器接管”右侧出现圆点，说明为“浏览器：人工接管中”；释放接管后圆点消失

#### Scenario: 有未保存修改时切换设置项
- **WHEN** 管理员修改了发送限制但未保存，在左栏点击“模型”
- **THEN** 页面询问保留编辑还是放弃；选择保留时停留在“运行与发送”，修改内容不变

## ADDED Requirements

### Requirement: 健康与日报分组排版

设置页“健康与日报”项 MUST 在顶部用一行显示总状态、非正常项数与采样时间；指标 MUST 按运行、采集、发送、浏览器、账号、基础设施分组，以表格行展示，每行包含状态圆点、中文名称、状态和说明。组内非正常项 MUST 排在正常项之前并完整显示说明；正常项在宽屏下可两项一行。账号检查结果 MUST 并入“账号”组，显示检查时间和“检查计划”入口，同一检查不得在页面上出现两次。每个已知指标 MUST 有中文名称；未知指标归入“其他”组并显示其标识，不得使用同一个通用名称代替多个指标。每日日报 MUST 以表格展示，每天一行，直接显示调用次数、token、估算费用、公开与私信的入站／回复／失败、响应时间中位数与 P90、告警数；告警历史和健康与披露配置默认收起。本要求只改变展示，指标判定、告警、日报内容与配置含义不变。宽度不超过 860px 时，指标改为单列，日报表格在自身容器内横向滚动，页面整体不得横向溢出。

#### Scenario: 多数指标正常
- **WHEN** 健康接口返回 20 项指标，其中 4 项需关注
- **THEN** 顶部显示“需关注 4 项”与采样时间；每组中需关注的项排在最前并显示完整说明；在 1440×900 的视口内无需滚动即可看到全部 20 项的名称和状态

#### Scenario: 账号检查不重复
- **WHEN** 健康接口同时返回三项账号合规指标和账号检查结果
- **THEN** 三项检查只在“账号”组中各出现一次，组内显示检查时间和“检查计划”入口

#### Scenario: 指标缺少名称映射
- **WHEN** 健康接口返回一个页面未登记的指标标识
- **THEN** 该指标出现在“其他”组，名称显示其标识，状态与说明照常显示

#### Scenario: 查看日报
- **WHEN** 已归档三天日报
- **THEN** 日报表格显示三行，每行直接显示当天的调用、token、费用、两个渠道的入站／回复／失败、响应时间和告警数，无需逐行展开

#### Scenario: 窄屏查看健康页
- **WHEN** 管理员在 375px 宽度下打开“健康与日报”
- **THEN** 指标单列显示，日报表格只在表格区域内横向滚动，页面没有整体横向溢出
