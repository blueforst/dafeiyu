# 消息工作流增量规格（回复文风）

## ADDED Requirements

### Requirement: 回复格式标记

系统 MUST 在生成公开回复或私信后，用确定性规则检查正文是否含编号或项目符号列表、分步说明、Markdown 标题或加粗，并在消息上记录命中的类别。草稿卡片和已发送消息的详情 MUST 显示该标记。该检查 MUST NOT 改变发送流程：自动模式照常自动发送，草稿模式照常由管理员审批；检查不得发起模型请求，也不得改写正文。

#### Scenario: 自动模式生成了分步做法
- **WHEN** 自动模式下生成的回复是分两行以上写的“1. …”“2. …”分步做法
- **THEN** 系统照常自动发送，消息详情显示正文含列表或步骤

#### Scenario: 草稿模式审批
- **WHEN** 草稿模式下生成的回复含 Markdown 加粗
- **THEN** 草稿卡片显示含 Markdown 的提示，管理员批准后才发送

#### Scenario: 改写后标记消失
- **WHEN** 管理员把带列表的草稿改写成普通口语后批准
- **THEN** 发送的消息不再带格式标记

#### Scenario: 句首小数不算列表
- **WHEN** 回复以“3.5 分也太低了吧”开头
- **THEN** 系统不标记为列表
