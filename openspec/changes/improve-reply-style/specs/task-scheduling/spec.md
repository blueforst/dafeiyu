# 定时任务增量规格（回复文风）

## MODIFIED Requirements

### Requirement: 早晚安任务默认与内容

系统 MUST 提供默认北京时间 08:00 的早安和 23:00 的晚安任务，初始关闭；启用后用当前人设、当日日程和角色经历经 LLM 生成，采用正常正文校验、额度和平台回执。角色经历包含最近已确认发出的帖子；提示词 MUST 要求本帖不重复这些帖子的开头、句式和切入点，并以今日日程为准，不把以前帖子里的事写成今天又发生一次。生成的正文含列表、分步说明或 Markdown 格式时，系统 MUST 照常提交，并在任务记录中标记命中的类别。

#### Scenario: 刚完成系统升级
- **WHEN** 管理员尚未启用新早晚安任务
- **THEN** 系统不会因升级或回复验收自动发布问候帖

#### Scenario: 启用的早安任务执行
- **WHEN** 任务到期且业务正常运行、额度可用
- **THEN** 系统保存生成正文后提交，并记录模型费用和平台回执

#### Scenario: 连续几天的早安帖
- **WHEN** 前两天的早安帖都已确认发出，今天的早安任务执行
- **THEN** 提示词的角色经历包含前两天的帖子，提醒区要求本帖不重复它们的开头、句式和切入点

#### Scenario: 生成的帖子含列表
- **WHEN** 早安任务生成的正文是编号列表
- **THEN** 系统照常提交该帖，任务执行历史显示含列表或步骤的标记
