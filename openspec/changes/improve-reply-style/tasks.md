## 1. 提示词

- [x] 1.1 近期往来单独成段（design.md 第 1 节）：`assembleReplyPrompt` 从 memory 中取出 `recent`，生成“与对方的近期往来”段，并附固定说明；没有往来时显示“暂无”；`REPLY_PROMPT_VERSION` 在当前值上加一。验收：服务器单元测试覆盖：
  - 分段顺序，以及记忆段不再含 `recent`；
  - 为用户乙生成时不含给用户甲的回复；
  - 公开回复不含私信往来；
  - 已遗忘用户为空；
  - 只生成草稿的那次往来不带回复；
  - 旧回放快照能重新组装。
- [x] 1.2 去掉跨人开头提醒（design.md 第 2 节）：`buildReplyHints` 不再生成 `opening`；`openingEnabled`、`openingCount` 仍可读取和保存，但不再生效；人设页“动态提醒”不再显示这两项。验收：
  - 服务器单元测试确认不再出现开头提醒、旧设置可读写、表情节制结果不变；
  - 服务器隔离 Camoufox 确认界面不再显示这两项。

## 2. 早晚安帖

- [x] 2.1 早晚安帖带上角色经历，并加 `post-variety` 提醒（design.md 第 3 节）。验收：服务器单元测试（模拟模型）确认：
  - 角色经历包含最近确认的帖子；
  - 提醒区有帖子去重提醒；
  - 被隐藏的帖子不出现；
  - 回复的提示词没有这条提醒。

## 3. 格式标记

- [x] 3.1 在 `src/reply-style.ts` 新增 `formatIssues()`，并按 design.md 第 4 节收紧 `hasSteps`：编号后紧跟数字不算，列表至少两行。人设回放统计共用这套规则。验收：服务器单元测试覆盖 design.md 列出的应命中和不应命中的样例。
- [x] 3.2 接入标记（只标记，不改变发送流程）：
  - 生成回复和私信后保存 `draft.format`；管理员改写或重写后重新计算；
  - 动态页的草稿卡片和已发送消息详情显示格式提示；
  - 早晚安帖照常提交，任务记录和任务执行历史显示格式提示；
  - 试聊返回并显示 `format`。

  验收：
  - 服务器工作流测试（模拟模型）覆盖：
    - 自动模式下含列表的回复照常发送并带标记，模型调用次数不变；
    - 草稿模式下不批准不发送；
    - 改写后标记消失；
    - 早晚安帖照常提交并带标记；
  - 服务器隔离 Camoufox 确认试聊、草稿卡片、消息详情和任务执行历史显示格式提示。
