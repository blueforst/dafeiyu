# 主程序可观测性增量规格

## MODIFIED Requirements

### Requirement: 实时阶段与关联信息

系统 MUST 展示等待、身份检查、公开／私信采集、排队、上下文、记忆召回、语义判定、生成、发送、回查、整理、退避及错误阶段，包含开始时间、持续时间、轮次和可用关联 ID。

#### Scenario: 一条消息进入语义判定
- **WHEN** 工作流开始该消息的触发规则判定
- **THEN** 设置页“排查问题”区显示语义判定阶段、耗时和该消息的关联信息

### Requirement: 队列和运行设置

设置页“排查问题”区 MUST 显示队列状态、最近完成轮次、下次循环、通道额度与退避；正常运行模式在设置页运行模式分区配置，额度在发送限制分区配置；轮询间隔只在定时任务分区维护。

#### Scenario: 通道正在退避
- **WHEN** 某通道在退避时段内
- **THEN** 页面显示该通道的退避原因与结束时间，不把等待显示成无故卡住
