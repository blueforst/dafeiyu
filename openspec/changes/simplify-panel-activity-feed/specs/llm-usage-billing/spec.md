# 模型计量增量规格

## MODIFIED Requirements

### Requirement: 流水数据最小化

计费记录 MUST 不保存提示词、回复正文或完整密钥，页面与接口沿用管理鉴权；人设页、动态条目详情和设置页任务执行历史可以引用同一流水的费用，不重复记账。

#### Scenario: 从任务历史查看生成费用
- **WHEN** 管理员在设置页任务执行历史中打开某次早安任务的费用详情
- **THEN** 系统引用原调用流水，不新增费用记录或泄露请求正文与密钥

#### Scenario: 从动态查看回复费用
- **WHEN** 管理员展开一条回复的详情
- **THEN** 显示的费用来自该回复关联的原调用流水，与计费页一致，不新增费用记录

### Requirement: 计费页汇总与流水

计费页 MUST 提供今日、本月和自选日期范围的请求数、token、美元估算及未定价数量，展示每日趋势、按模型／用途汇总及有限分页调用明细；筛选口径必须一致。页面按 ZCode 用量统计布局组织：顶部汇总条，其下依次为活动热力图、范围切换、按模型每日趋势与用量占比，调用流水默认收起，自选日期范围位于更多筛选中。

#### Scenario: 切换日期范围
- **WHEN** 管理员选择新的北京时间日期范围
- **THEN** 汇总、趋势和流水使用同一范围，金额注明 Pi 目录估算

#### Scenario: 只有未定价请求
- **WHEN** 当前范围内没有可估价调用
- **THEN** 页面明确显示未定价数量和未知费用，不把估算总额零误作全部免费

#### Scenario: 默认进入计费页
- **WHEN** 管理员打开计费页且未选择范围
- **THEN** 页面显示汇总条、热力图与近 7 日趋势和占比，调用流水处于收起状态且未请求

## ADDED Requirements

### Requirement: 计费汇总条

计费页顶部 MUST 以一行汇总条展示累计 token、累计可估算费用、单日 token 峰值、近 7 日缓存读取占比和近 7 日平均每次回复费用；存在未定价或未知调用时，费用旁必须显示其数量，不得把它们计为零。

#### Scenario: 存在未定价调用
- **WHEN** 累计调用中有 12 次未定价
- **THEN** 累计费用旁显示另有 12 次未定价，累计费用只包含可估算部分

#### Scenario: 没有返回缓存用量
- **WHEN** 近 7 日调用都没有返回缓存读取字段
- **THEN** 缓存读取占比显示未知而不是 0%

### Requirement: 活动热力图

计费页 MUST 展示最近 52 个自然周的按北京日期活动热力图，首行为周日，支持每日、每周、累计三种视图；悬停或聚焦格子时显示日期或周范围、token、调用数及可估算费用。没有调用的日期显示为空格子，窄屏下不产生页面横向滚动。

#### Scenario: 查看某一天
- **WHEN** 管理员悬停或键盘聚焦某个日期格
- **THEN** 提示框显示该北京日期的 token、调用数和可估算费用

#### Scenario: 切换为累计视图
- **WHEN** 管理员选择累计
- **THEN** 每列显示截至该周的累计 token，悬停时高亮整列

### Requirement: 按模型每日趋势

计费页 MUST 提供近 7 日与近 30 日两种范围的每日趋势折线，每个模型一条线，最多显示五个模型、其余合并为其他模型；缺少调用的日期补零，可在 token 与可估算费用之间切换，费用视图不得把未定价调用计为零。提示框数值使用中文紧凑单位并带单位名称。

#### Scenario: 某日没有调用
- **WHEN** 近 7 日中某一天没有任何调用
- **THEN** 该日在各模型线上显示为 0，日期轴保持连续

#### Scenario: 切换到费用视图
- **WHEN** 某模型全部调用未定价且管理员切换到费用
- **THEN** 该模型标注未定价，不显示为 0 美元的折线

### Requirement: 用量占比

计费页 MUST 用环形图展示当前范围内按模型或按用途的 token 占比，超过六个分区时合并为其他；旁边的明细列出每项的百分比、token 与可估算费用或未定价标记，并提供与图形等价的表格视图供无障碍读取。

#### Scenario: 按用途查看
- **WHEN** 管理员切换为按用途
- **THEN** 环形图与明细按回复、语义触发、虚构日程、记忆整理等用途分区

### Requirement: 计费数字与主题

计费页 MUST 用中文紧凑单位（万、亿）展示 token，数字使用等宽字体、单位文字弱化；图表配色在浅色与深色主题下均可辨认，375px 宽度下不产生整体横向溢出。

#### Scenario: 深色主题窄屏
- **WHEN** 管理员在深色主题、375px 宽度打开计费页
- **THEN** 汇总条纵向排列，热力图等分宽度且无横向滚动，图表颜色清晰可辨
