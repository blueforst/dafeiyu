# 对话记忆增量规格

## MODIFIED Requirements

### Requirement: 近期互动上下文

系统 MUST 默认向回复生成提供七天以内最近三次已处理互动中的入站原文，只把已确认发送的回复作为已经说过的话；近期数量和原文保留策略可在设置页记忆策略分区配置，原文默认保留三十天。

#### Scenario: 存在未发送草稿
- **WHEN** 用户的近期记录包含一条草稿和一条已确认回复
- **THEN** 上下文可包含收到的原文，但只有已确认回复被标识为角色已发送内容

#### Scenario: 近期记录超过时间窗口
- **WHEN** 某条原始互动已超过七天且仍存在数据库中
- **THEN** 默认近期上下文不包含它，符合来源约束的长期记忆可按规则继续使用
