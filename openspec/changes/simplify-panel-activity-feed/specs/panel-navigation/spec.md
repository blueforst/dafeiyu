# 五页面板导航增量规格

## MODIFIED Requirements

### Requirement: 一级页面导航

管理面板 MUST 恰好提供动态、人设、记忆、设置、计费五个一级页面，默认打开动态页。原模型、主程序、定时任务三页的内容并入设置页对应分区；旧地址 `#/overview`、`#/model`、`#/program`、`#/tasks`、`#/browser` MUST 跳转到对应新位置，不显示空白页或错误。

#### Scenario: 默认进入概览
- **WHEN** 管理员打开未指定页面的面板地址
- **THEN** 系统显示动态页，导航恰好包含五个约定页面

#### Scenario: 页面地址直接访问
- **WHEN** 管理员访问旧地址 `#/model`、`#/program`、`#/tasks` 或 `#/overview`
- **THEN** 前三者打开设置页并展开模型、排查问题或定时任务分区，`#/overview` 打开动态页

#### Scenario: 直接访问新增页面
- **WHEN** 管理员打开 `#/persona`、`#/memory`、`#/settings`、`#/billing` 或设置页的分区地址
- **THEN** 系统打开对应页面或分区，不要求先经过动态页

### Requirement: 浏览器人工接管

系统 MUST 在设置页“排查问题”区提供浏览器人工接管，排空自动操作并进入接管后才允许桌面连接；释放接管必须断开交互连接并保持暂停。浏览器未登录或需要人工处理时，动态页 MUST 显示提示并链接到接管区。旧地址 `#/browser` MUST 打开设置页并展开接管区。

#### Scenario: 非接管状态连接桌面
- **WHEN** 管理员在非人工接管状态访问桌面入口
- **THEN** 系统拒绝连接并提示先接管

#### Scenario: 释放人工接管
- **WHEN** 管理员释放已连接的人工接管
- **THEN** 浏览器交互连接断开，自动处理不恢复

#### Scenario: 需要人工登录
- **WHEN** 浏览器状态显示需要人工处理验证码或登录
- **THEN** 动态页顶部显示提示，点击后打开设置页接管区

### Requirement: 页面职责和同源设置

系统 MUST 在人设页“今日日程”标签管理日程内容、在设置页定时任务分区管理生成计划，两处共享同一有效设置和结果；运行模式、模型、定时任务、发送限制和记忆策略只在设置页维护，各自只有一份可编辑配置。

动态页 MUST 不显示日志；设置页“排查问题”区 MUST 集中展示行式日志，包含时间、事件和说明，并保留筛选及暂停实时能力，同时提供阶段记录、当前队列和任务执行历史。

#### Scenario: 查看日志
- **WHEN** 管理员从动态页进入设置页“排查问题”区
- **THEN** 动态页没有日志区，排查问题区提供行式日志列表、阶段记录、队列和任务执行历史

#### Scenario: 调整日程生成时间
- **WHEN** 管理员在设置页定时任务分区保存新的生成时间
- **THEN** 人设页“今日日程”标签显示同一时间，不出现第二份可冲突的调度配置

### Requirement: 主题与窄屏可用性

五个页面 MUST 支持系统浅色／深色、375px 宽度、加载／空数据／错误状态以及未保存编辑离页提示，外部文本须按纯文本显示。

#### Scenario: 窄屏查看动态
- **WHEN** 管理员在 375px 宽度下打开动态页并编辑一条草稿
- **THEN** 可阅读原话和回复、修改草稿并发送，页面不产生整体横向溢出

#### Scenario: 未保存编辑离页
- **WHEN** 管理员修改人格后切换页面但尚未保存
- **THEN** 页面提供保留编辑或明确放弃的选择，不静默丢失内容

## ADDED Requirements

### Requirement: 设置分区折叠与摘要

设置页 MUST 把每类设置收成一个分区，未展开时标题行显示当前值摘要；运行模式 MUST 在标题行直接切换，不需展开。分区展开后才显示可编辑字段，每个分区独立保存，保存不得隐式恢复处理或发送消息。

#### Scenario: 浏览设置页
- **WHEN** 管理员打开设置页
- **THEN** 只看到各分区标题行及摘要，例如模型名称与上次测试结果、各定时任务开启数量与下一次执行时间

#### Scenario: 切换运行模式
- **WHEN** 系统暂停时管理员把运行模式从草稿切换为自动发送
- **THEN** 系统保存新模式并保持暂停，标题行显示新模式

### Requirement: 操作提示分级

会调用模型并计费的操作 MUST 在按钮上带“计费”标记并提供说明；会真实提交到 X 的操作 MUST 在操作处明确提示。其余固定说明文字 MUST 收起或移除，不得在每个字段下重复显示。

#### Scenario: 查看重写按钮
- **WHEN** 管理员查看草稿的“重写”按钮
- **THEN** 按钮带“计费”标记，悬停或聚焦时说明会调用模型并计费

#### Scenario: 批准发送草稿
- **WHEN** 管理员查看草稿的“发送”按钮
- **THEN** 操作处说明批准后会由主循环真实发送到 X
