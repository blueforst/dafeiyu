# 定时任务增量规格

## MODIFIED Requirements

### Requirement: 单一主循环

系统 MUST 使用一个主循环，默认在一轮结束后等待六十秒，可设置三十至三千六百秒；主循环的启停只由全局运行控制（暂停／恢复）决定，设置页定时任务分区只维护等待间隔，不提供第二个启停开关。

#### Scenario: 本轮执行耗时较长
- **WHEN** 某轮处理超过配置等待间隔
- **THEN** 系统等待该轮结束后再计时，不叠加启动第二轮

#### Scenario: 修改主循环间隔
- **WHEN** 系统暂停时管理员在定时任务分区保存新的主循环间隔
- **THEN** 新间隔被保存，系统保持暂停

### Requirement: 独立健康检查与受限维护

宿主健康检查 MUST 保持每五分钟运行且独立于 app 及业务暂停，结果可在设置页定时任务分区查看；维护入口只接受限定任务，不能执行任意命令或削弱容器隔离。

#### Scenario: 应用不可用
- **WHEN** app 故障而宿主仍运行
- **THEN** 独立检查记录应用不可达，不因 app 内调度失效而停止检测

#### Scenario: 请求任意命令
- **WHEN** 管理接口收到不属于支持任务的执行请求
- **THEN** 系统拒绝请求，不把输入交给 shell 执行

### Requirement: 证书续期连续性

设置页对任务的整合 MUST 保留宿主现有证书续期机制，并展示相关健康结果，不因维护任务整合而关闭续期。

#### Scenario: 业务暂停期间证书将到期
- **WHEN** 宿主续期检查到达
- **THEN** 续期机制继续按原规则工作，结果可供健康状态读取
