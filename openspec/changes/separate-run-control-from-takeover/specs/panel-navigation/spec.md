# 面板导航增量规格（顶部运行状态与浏览器接管分离）

## MODIFIED Requirements

### Requirement: 全局控制与配置保存

管理面板 MUST 在每个页面的顶部栏显示运行状态标识，并提供启动和暂停：
- 运行中显示“运行中”和“暂停”；
- 已暂停显示“已暂停”和“启动”；
- 等待当前操作结束时显示“正在暂停…”，不提供启停操作。

顶部栏 MUST NOT 提供发起或释放人工接管的按钮。人工接管期间，顶部栏显示“已暂停”，“启动”不可用并说明需要先释放接管，同时提供链接打开设置页的浏览器接管分区。启动和暂停 MUST NOT 改变运行模式。保存任何页面的配置不得隐式恢复处理或发送消息，配置应在约定的后续轮次或任务执行中生效。

#### Scenario: 暂停时保存模型
- **WHEN** 系统处于暂停状态且管理员保存有效模型配置
- **THEN** 系统仍保持暂停，配置用于后续显式恢复后的处理

#### Scenario: 保存人设或任务设置
- **WHEN** 系统暂停且管理员保存人设、记忆策略或任务计划
- **THEN** 系统不因保存而恢复或发帖

#### Scenario: 从顶部栏启动和暂停
- **WHEN** 系统已暂停，管理员点击顶部栏的“启动”
- **THEN** 顶部栏显示“运行中”和“暂停”，运行模式保持不变；再点击“暂停”后，先显示“正在暂停…”，当前操作结束后显示“已暂停”和“启动”

#### Scenario: 人工接管期间查看顶部栏
- **WHEN** 系统处于人工接管，管理员打开任一页面
- **THEN** 顶部栏显示“已暂停”，“启动”不可用并说明需要先释放接管，顶部栏没有释放接管按钮，只有指向浏览器接管分区的链接

#### Scenario: 从顶部栏前往接管分区
- **WHEN** 人工接管期间管理员点击顶部栏的接管链接
- **THEN** 系统打开设置页并展开浏览器接管分区

### Requirement: 浏览器人工接管

系统 MUST 在设置页“排查问题”区提供浏览器人工接管，排空自动操作并进入接管后才允许桌面连接；发起接管、查看接管状态、连接桌面和释放接管 MUST 都在该接管区完成。释放接管必须断开交互连接并保持暂停。接管区标题行 MUST 随状态显示是否处于人工接管。浏览器未登录或需要人工处理时，动态页 MUST 显示提示并链接到接管区。旧地址 `#/browser` MUST 打开设置页并展开接管区。

#### Scenario: 非接管状态连接桌面
- **WHEN** 管理员在非人工接管状态访问桌面入口
- **THEN** 系统拒绝连接并提示先接管

#### Scenario: 释放人工接管
- **WHEN** 管理员在接管区释放已连接的人工接管
- **THEN** 浏览器交互连接断开，自动处理不恢复，顶部栏显示“已暂停”且“启动”可用

#### Scenario: 已接管但未连接桌面时释放
- **WHEN** 系统处于人工接管但管理员尚未连接桌面，在接管区点击释放接管
- **THEN** 系统回到已暂停，接管区标题行不再显示人工接管

#### Scenario: 需要人工登录
- **WHEN** 浏览器状态显示需要人工处理验证码或登录
- **THEN** 动态页顶部显示提示，点击后打开设置页接管区
