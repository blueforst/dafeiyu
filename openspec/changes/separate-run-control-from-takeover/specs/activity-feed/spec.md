# 动态页增量规格（顶部运行状态与浏览器接管分离）

## MODIFIED Requirements

### Requirement: 首页概况行

动态页顶部 MUST 用一行显示运行模式、当前模型和登录账号，取代原主页面的运行、账号、模型卡片；运行状态和启动／暂停由全局顶部栏提供，概况行不再重复。配置错误、通道退避和待回查数量在该行下方以提示显示。

#### Scenario: 草稿模式运行中
- **WHEN** 系统处于运行中且运行模式为草稿
- **THEN** 顶部栏显示“运行中”和“暂停”按钮，概况行显示“草稿模式”、模型名称和登录账号

#### Scenario: 公开通道退避
- **WHEN** 公开通道处于平台拒绝后的退避期
- **THEN** 概况行下方显示退避结束时间
