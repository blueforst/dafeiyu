# 同文重复改为降优先级

## Why

本轮真实试聊发现，三位不同用户一小时内提出相同普通问题会被直接过滤，公开与私信还会混合计数。2026-10-29 管理员确认改为同文重复只降低优先级，广告仍照常过滤。

## What Changes

- 只在同一工作账号、同一渠道内统计一小时不同用户的同文命中，保留原规范化、六字下限和可设阈值。
- 达到阈值后，当前与仍排队的同文消息转普通优先级，原因为“同文重复，降低优先级”，继续等待生成。
- 重点名单、人工补录、明确重新排队及重写保留优先。纯招呼和骚扰冷却沿用原规则。
- 广告关键词配链接或纯广告关键词继续入队过滤。历史已过滤、已发送、unknown 与出站均不批量改写。
- 设置标签改为同文重复降优先阈值，明确不会直接过滤。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `reply-triage`：修改广告与批量刷量过滤中的同文行为；本变更在 `add-reply-triage` 之后归档。

## Impact

修改 `src/reply-triage.ts`、设置文案、回归与说明，无新迁移或模型请求。降优先的消息随后按正常流程计费与校验；单条、小时、每日额度及暂停控制不变。本轮已有实现、部署和推送授权。
