# 同文降优先实现

本机只编辑；验证在服务器独立候选环境。

1. 广告判定仍先执行。精确重点名单和招呼判定之后，才把达到同文阈值的普通内容归 normal；不再调用 filtered 终态。
2. 命中统计在现有 `triage_text_hits` 联查 `messages.channel`，不新增表或索引。仍按一小时、不同用户计数；过时命中不由刷新续期。
3. 回查仍排队同文时只更新可降级项的 tier 与原因；人工标记、重写、重点名单保留优先。已处理终态及冻结出站不变。
4. 设置接口字段 `batchThreshold` 和 2—20 范围不变，只改界面名称与说明。
5. 回退成对旧镜像后恢复原硬过滤策略；没有逆迁移或历史消息批量转换。原始红测和最终服务器、工作区回归证据分别保留。
