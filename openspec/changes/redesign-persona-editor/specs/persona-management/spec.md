# 人设管理增量规格（人设编辑区目录加编辑）

## ADDED Requirements

### Requirement: 人设编辑区目录

人设模式中选中“我的人设”里的某个人设或某个内置预设时，主区 MUST 分为左侧段落目录和右侧编辑区，不得再以卡片网格同时展开全部段落。

目录 MUST 依次分为三组：
- “始终生效”：四个分区，按人设中的顺序排列；
- “触发卡”：按卡片顺序排列，组标题旁有添加按钮；
- “只读”：固定规则；查看角色预设或从角色预设新建的人设时，还有建议简介。

组标题 MUST 显示该组字数。每项 MUST 显示名称、字数和内容开头（最多两行）；触发卡项显示“什么时候用”的开头。触发卡项 MUST 带启用开关，点开关只切换启用状态，不改变选中项。

相邻两项之间 MUST 有分隔线，组与组之间的分隔更明显，选中项用底色标出。目录项 MUST NOT 显示占比条或百分比。有未保存修改的项 MUST 在名称后显示标记，读屏时读作“未保存”。

打开人设时默认选中第一个始终生效分区。在同一人设内切换选中项 MUST NOT 丢失未保存的修改，也不弹出离开确认。

#### Scenario: 打开使用中人设
- **WHEN** 管理员在 1440×868 窗口打开带四个分区、两张触发卡的使用中人设
- **THEN** 目录在一屏内列出四个分区、两张触发卡和固定规则，每项带字数和开头预览；编辑区显示“角色定义”

#### Scenario: 改完一段再切换
- **WHEN** 管理员修改“说话风格”后，在目录中点“记忆与承诺”
- **THEN** 编辑区换成记忆与承诺，不弹出离开确认；目录中“说话风格”名称后出现未保存标记，页头显示未保存；切回“说话风格”后修改仍在

#### Scenario: 在目录中关闭一张卡
- **WHEN** 管理员点“被夸”项上的开关
- **THEN** “被夸”变为关闭，编辑区仍显示原来选中的项，页头显示未保存

#### Scenario: 添加触发卡
- **WHEN** 管理员点触发卡组标题旁的添加按钮
- **THEN** 该组末尾出现一张启用的空白卡并被选中，焦点在卡名输入框

### Requirement: 人设编辑区单项编辑

编辑区 MUST 一次只显示目录中选中的一项。编辑区页头 MUST 写出名称、所属组和字数；页头下方有一句说明，写这一项该写什么；页头还 MUST 提供切换到目录中上一项、下一项的按钮，按钮上写出相邻项的名称。

始终生效分区 MUST 用一个输入框编辑全文，输入框撑满编辑区剩余高度，内容超出时在框内滚动。

触发卡 MUST 在名称前显示启用开关，并用卡名、什么时候用、内容三个输入框编辑。每个输入框都有标题和字数，内容框撑满剩余高度。上移、下移和删除卡片放在编辑区页头的更多菜单中；管理员也 MUST 能在目录中拖动触发卡调整顺序。

保存方式、20,000 字上限、修订号和生效时机保持不变。宽度不超过 860px 时，目录 MUST 改为编辑区顶部的下拉选择，页面不得整体横向滚动。

#### Scenario: 编辑长分区
- **WHEN** 管理员选中 384 字的“说话风格”
- **THEN** 全文显示在一个撑满编辑区的输入框中，不再挤在 5 行高的小框里滚动

#### Scenario: 编辑触发卡
- **WHEN** 管理员在目录中选中“不给步骤”
- **THEN** 编辑区显示启用开关，以及卡名、什么时候用、内容三个输入框，各写字数；更多菜单中有上移、下移和删除卡片

#### Scenario: 拖动排序
- **WHEN** 管理员在目录中把“被夸”拖到“不给步骤”上方
- **THEN** 两张卡交换顺序，页头显示未保存；保存后回复使用的触发卡目录按新顺序排列

#### Scenario: 用按钮切换
- **WHEN** 管理员选中“互动边界”后点“不给步骤 ›”
- **THEN** 编辑区换成“不给步骤”，目录中的选中项随之移动

#### Scenario: 窄屏编辑
- **WHEN** 管理员在 375px 宽度下打开人设，在顶部下拉中选择“被夸”
- **THEN** 编辑区显示“被夸”的三个输入框，页面没有横向滚动

### Requirement: 可编辑与只读内容区分

人设编辑区中可以修改的内容 MUST 显示为白底、带边框的输入框，聚焦时显示品牌色描边。不能修改的内容 MUST 显示为灰底、无边框、不能输入的文字区，并在标题旁写“只读”。说明文字和字数 MUST 以普通文字显示，不放进输入框或只读区。

以下内容 MUST 按只读显示：
- 固定规则：显示全文；
- 建议简介：同时提供“复制建议简介”按钮；
- 查看内置预设时的全部分区和触发卡各项：触发卡开关不可操作，页头只有“以此新建”。

只读区的文字 MUST 可以选中复制。

#### Scenario: 查看固定规则
- **WHEN** 管理员在目录中选中“固定规则”
- **THEN** 编辑区以灰底显示固定规则全文，标题旁写“只读”，不能输入

#### Scenario: 查看内置预设
- **WHEN** 管理员选中内置预设“大肥鱼”，在目录中点“说话风格”
- **THEN** 说话风格以灰底只读显示并标“只读”；目录中触发卡的开关不可操作，页头只有“以此新建”

#### Scenario: 复制建议简介
- **WHEN** 管理员查看从“大肥鱼”新建的人设，在目录中选中“建议简介”
- **THEN** 编辑区只读显示建议简介；点“复制建议简介”后提示已复制，剪贴板不可用时选中文字并提示手动复制
