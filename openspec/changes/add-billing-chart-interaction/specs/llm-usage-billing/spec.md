# 模型计费增量规格（图表交互）

## MODIFIED Requirements

### Requirement: 活动热力图

计费页 MUST 展示最近 52 个自然周、按北京日期汇总的活动热力图，首行为周日，支持每日、每周、累计三种视图。指针悬停或键盘聚焦格子时，MUST 立即显示带样式的提示框：每日视图显示日期与星期，每周视图显示周范围，累计视图显示截至日期；下一行显示 token、调用数和可估算费用，有未定价调用时附次数。当前格子 MUST 有可见描边；每周与累计视图悬停时高亮整列。没有调用的日期显示为空格子，窄屏下不产生页面横向滚动。

#### Scenario: 查看某一天
- **WHEN** 管理员把指针移到某个日期格上
- **THEN** 不需要停顿，提示框就显示该北京日期与星期，以及 token、调用数和可估算费用

#### Scenario: 键盘查看某一天
- **WHEN** 管理员用键盘聚焦热力图并移动到某个日期格
- **THEN** 该格出现描边，并显示与悬停相同内容的提示框

#### Scenario: 切换为累计视图
- **WHEN** 管理员选择累计并悬停某一列
- **THEN** 整列高亮，提示框显示截至该周的累计 token

### Requirement: 按模型每日趋势

计费页 MUST 提供近 7 日与近 30 日两种范围的每日趋势折线，每个模型一条线，最多显示五个模型，其余合并为其他模型；缺少调用的日期补零；可在 token 与可估算费用之间切换，费用视图不得把未定价调用计为零。指针悬停在某个日期对应的整列区域内时，MUST 显示竖向参考线、放大该日各模型的点，并显示提示框：标题为日期、星期及所显示模型的合计，每个模型一行（色块、名称、数值），按数值从大到小排列，不列出数值为零的模型。提示框数值使用中文紧凑单位并带单位名称。

#### Scenario: 悬停某一天
- **WHEN** 管理员把指针移到近 7 日趋势图中某一天的竖向区域，不必对准折线上的点
- **THEN** 出现参考线，提示框列出该日各模型的 token 与合计

#### Scenario: 某日没有调用
- **WHEN** 近 7 日中某一天没有任何调用
- **THEN** 该日在各模型线上显示为 0，日期轴保持连续，悬停时提示框只显示合计为 0

#### Scenario: 切换到费用视图
- **WHEN** 某模型全部调用未定价且管理员切换到费用
- **THEN** 该模型标注未定价，不显示为 0 美元的折线，悬停提示框中该模型显示“未定价”

### Requirement: 用量占比

计费页 MUST 用环形图展示当前范围内按模型或按用途的 token 占比，超过六个分区时合并为其他；旁边的明细列出每项的百分比、token 与可估算费用（或未定价标记），并提供与图形等价的表格视图供无障碍读取。指针悬停或键盘聚焦扇区时，MUST 突出该扇区、淡化其他扇区，并显示名称、token、占比与可估算费用或“未定价”；悬停明细行时 MUST 突出对应扇区。

#### Scenario: 按用途查看
- **WHEN** 管理员切换为按用途
- **THEN** 环形图与明细按回复、语义触发、虚构日程、记忆整理等用途分区

#### Scenario: 悬停扇区
- **WHEN** 管理员把指针移到“回复”扇区
- **THEN** 该扇区突出、其余淡化，提示框显示回复的 token、占比和可估算费用

#### Scenario: 悬停明细行
- **WHEN** 管理员把指针移到明细中的“语义触发”一行
- **THEN** 环形图中语义触发扇区突出显示

## ADDED Requirements

### Requirement: 图表提示框与指针交互

计费页图表的提示框 MUST 在指针进入目标时立即出现，并在离开、按 Esc 或点击空白处时关闭；样式随浅色与深色主题变化，在图表区域内自动翻转和夹紧，不遮挡指针所在的目标，不产生页面横向滚动。触屏设备上，轻点目标即显示提示框，轻点空白处关闭。图表 MUST 不同时出现浏览器原生提示与自定义提示框，并保留供读屏使用的文字说明。

#### Scenario: 靠近右边缘的格子
- **WHEN** 管理员在 375px 宽度下悬停热力图最右侧的格子
- **THEN** 提示框向左展开且完整可见，页面没有横向滚动条

#### Scenario: 触屏查看趋势
- **WHEN** 管理员在触屏上轻点趋势图中的某一天
- **THEN** 显示该日的提示框，轻点图表外的空白处后提示框关闭

#### Scenario: 不出现两层提示
- **WHEN** 指针在同一格子上停留超过两秒
- **THEN** 只显示自定义提示框，不出现浏览器原生提示

### Requirement: 图表键盘浏览

热力图、趋势图和环形图 MUST 各自只占一个 Tab 停留点。进入后用方向键在格子、日期或扇区之间移动，Home 与 End 跳到首尾，Esc 关闭提示框；聚焦位置 MUST 可见，并显示与悬停相同的提示框。

#### Scenario: 键盘穿过计费页
- **WHEN** 管理员用 Tab 从汇总条移动到调用流水
- **THEN** 三张图各只需要一次 Tab 即可经过，不必逐个经过格子或数据点

#### Scenario: 方向键浏览热力图
- **WHEN** 管理员聚焦热力图后按右方向键
- **THEN** 焦点移到下一周的同一星期，提示框随之更新
