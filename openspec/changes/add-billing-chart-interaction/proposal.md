# 计费图表鼠标与键盘交互提案

## Why

计费页的三张图（活动热力图、按模型每日趋势、用量占比环形图）已经按 ZCode 样式随 0.1.17 上线，但实际上没有可用的鼠标交互：

- 唯一的“提示”是 SVG 自带的 `<title>`。浏览器要停顿约一秒才显示，样式不可控，键盘聚焦时也不显示。
- 趋势图只能悬停在半径 2.5 的小圆点上，很难对准；没有按日期整列悬停，也看不到当天各模型的数值对比。
- 环形图的扇区和右侧明细没有联动，悬停时没有任何高亮。
- 热力图 364 个格子、趋势图每个数据点、每个扇区都是单独的 Tab 停留点，键盘用户要按几百次 Tab 才能离开计费页。

现有规格（`simplify-panel-activity-feed` 的 `llm-usage-billing`）已经要求“悬停或聚焦格子时显示提示框”。任务 8.5 勾成了完成，但实现只满足了每周、累计视图的整列描边，提示框这一条没有做到。趋势图和环形图的悬停行为在规格里没有写明，所以实现也没有做。

ZCode 原版的三张图都有悬停后立即出现、带样式的提示框：

- 热力图按格子显示；
- 趋势图按整列显示当天日期、合计和各模型数值，0 用量的模型不列出；
- 环形图按扇区显示名称、token 和占比。

## What Changes

- **共用提示框**：三张图共用一个 HTML 提示框组件。指针悬停时立即出现，样式跟随浅色、深色主题。提示框包含标题行和数据行（色块、名称、等宽数字、弱化单位），在图表区域内自动翻转、夹紧，窄屏下不产生横向滚动。移开指针、按 Esc 或点击空白处时关闭。原生 `<title>` 移除以免出现两层提示，`aria-label` 保留。
- **热力图**：悬停或聚焦格子时显示提示框：每日视图为日期和星期，每周视图为周范围，累计视图为“截至某日”，下面一行是 token、调用数、可估算费用，有未定价调用时附上次数。当前格子加描边；每周、累计视图保留整列高亮。整张热力图只占一个 Tab 停留点，用方向键按天、按周移动，Home、End 跳到最早和最近。
- **按模型每日趋势**：每个日期对应一整列的悬停区域。悬停时显示竖向参考线，并放大该日各模型的点。提示框列出日期（含星期）和所显示模型的合计，每个模型一行，按数值从大到小排列，0 值不列出；费用视图中未定价模型显示“未定价”。图表只占一个 Tab 停留点，方向键切换日期。
- **用量占比**：悬停或聚焦扇区时，该扇区加粗、其余淡化，提示框显示名称、token、占比、可估算费用或“未定价”。悬停右侧明细行时，高亮对应扇区；反之亦然。
- **触屏**：轻点格子、日期列或扇区，显示对应提示框；轻点空白处关闭；不依赖悬停。
- 不引入图表库，继续使用内联 SVG 和原生 ES 模块。不改变数据接口、计算口径、配色和布局。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `llm-usage-billing`：修改“活动热力图”“按模型每日趋势”“用量占比”三项需求，新增“图表提示框与指针交互”和“图表键盘浏览”。

这三项需求目前只存在于未归档的 `simplify-panel-activity-feed` 中，因此本提案需要在它之后归档。实施可以直接基于当前代码开始。

## Impact

- **代码**：`public/js/charts/usage.js`（三张图的事件委托、悬停区域、键盘导航）、新增 `public/js/charts/tooltip.js`（共用提示框）、`public/style.css`（提示框、悬停与淡化样式、参考线）、`public/js/views/billing.js`（明细行与扇区联动）。
- **后端**：不改接口、数据库或计费口径。
- **界面验收**：在服务器隔离环境用 Camoufox 测试鼠标悬停、键盘、触屏模拟、浅色和深色、1440px 与 375px。
- **记录**：`simplify-panel-activity-feed` 的任务 8.5 不回滚勾选，未达标的提示框部分由本提案任务承接，并在实施记录中说明。
- 本次只创建规划文件。构建和测试在服务器隔离环境执行，不改变线上运行状态。
