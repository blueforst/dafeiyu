# 计费图表交互实施任务

当前 7/8 项已完成隔离实现与验证，任务 3.3 生产发布仍未完成。证据见 [实施记录](../../../docs/实施记录/2026-10-28-计费图表交互.md)。规格见 [llm-usage-billing](specs/llm-usage-billing/spec.md)，实现边界见 [design.md](design.md)。构建、测试和界面验收只在服务器隔离环境执行，不使用生产 profile；生产发布需要另行授权。

## 1. 共用提示框

- [x] 1.1 新增 `public/js/charts/tooltip.js` 和 `.chart-frame`、`.chart-tip` 样式：立即显示，跟随指针或锚定目标，翻转与夹紧，Esc、离开和外部点击时关闭，支持深浅色。定位计算写成纯函数。验收：服务器 Node 测试覆盖四个方向的翻转与夹紧；Camoufox 验收确认提示文本只以文本节点写入。
- [x] 1.2 实现 SVG 根节点上的事件委托、`requestAnimationFrame` 合并、按指针类型的分支（鼠标和笔悬停、触屏轻点、位移阈值），以及重建前清理监听。验收：Camoufox 验收验证切换视图十次后，外部点击监听不会累积，提示框只有一个。

## 2. 三张图

- [x] 2.1 热力图：删除格子的 `tabindex` 和 `<title>`，SVG 只保留一个 Tab 停留点；实现方向键、Home、End 与当前格描边，以及三种视图的提示框文案和整列高亮。验收：服务器单元测试覆盖三种视图的文案、未定价附注和跨周移动。
- [x] 2.2 趋势图：加入按日期整列的透明命中区域、参考线和放大点；提示框显示合计、按数值降序、过滤 0 值，费用视图中未定价模型显示“未定价”；实现键盘移动列。验收：服务器单元测试覆盖 0 值过滤、未定价、单日与 30 日边界列。
- [x] 2.3 环形图：实现扇区的突出与淡化、提示框，方向键切换扇区，以及明细行与扇区的双向联动；表格视图不受影响。验收：服务器单元测试覆盖“其他”分区与未定价文本。
