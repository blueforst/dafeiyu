# 面板统一设计规格（对话排版改版增量）

## ADDED Requirements

### Requirement: 对话流排版

使用新设计的对话流（人设页试聊与动态页往来） MUST 采用同一套排版。对方或测试用户的消息 MUST 只显示为右侧气泡，MUST NOT 在每条消息上下附加渠道、分级、时间或状态行。时间 MUST 居中分隔显示：第一条消息前、与上一条消息相隔五分钟以上或跨日时显示一次。角色一侧每条 MUST 以人设名称首字的圆形头像和人设名称开头，再显示正文；需要关注的结果和原因 MUST 直接显示，不需要悬停或展开。每条下方 MUST 有操作行，至少包含“详情”。时间、分级、耗时、费用、回执等摘要 MUST 只在该条被悬停、获得键盘焦点或被选中时显示，触屏设备上只在选中时显示。选中的一条 MUST 只以浅色底标示角色一侧，MUST NOT 以强调色填满整行。浅色和深色下 MUST 一致，375px 宽时不出现整体横向滚动。

#### Scenario: 一条普通往来
- **WHEN** 管理员打开一个会话，其中一条对方消息已得到角色回复
- **THEN** 对方消息只有气泡，上下没有渠道、分级和时间；回复左侧是人设名首字头像，上方是人设名，下方是含“详情”的操作行

#### Scenario: 间隔超过五分钟
- **WHEN** 同一会话的两条消息相隔八分钟
- **THEN** 第二条消息前居中显示一次时间；若只相隔两分钟则不显示

#### Scenario: 悬停查看摘要
- **WHEN** 管理员把鼠标移到一条回复上，再移开
- **THEN** 悬停期间回复下方出现时间、分级等摘要，移开后隐藏；用 Tab 键聚焦到这条回复时同样出现

#### Scenario: 触屏设备
- **WHEN** 管理员在不支持悬停的手机上浏览会话
- **THEN** 摘要默认隐藏，点选某一条后该条显示摘要

#### Scenario: 选中一条
- **WHEN** 管理员点击某条回复的“详情”
- **THEN** 只有这条回复显示浅色底，对方气泡没有选中样式，右栏显示该条详情；窄屏下右栏以浮层打开，按 Esc 关闭后焦点回到该“详情”按钮

### Requirement: 头像配色

左栏会话列表和对话流中的头像 MUST 显示名称的第一个完整字符，底色从一组固定配色中按条目标识稳定选取，同一条目每次显示的颜色相同。每组配色的文字与底色对比度 MUST 在浅色和深色下都不低于 4.5:1。

#### Scenario: 左栏头像可读
- **WHEN** 管理员在浅色或深色模式下打开动态页
- **THEN** 左栏每个会话头像中的字母或汉字都能清楚辨认，文字与底色对比度不低于 4.5:1

#### Scenario: 同一人设颜色稳定
- **WHEN** 同一个人设的回复出现在不同轮次，或刷新页面后再看
- **THEN** 它们的头像字和底色都相同；换成另一个人设时通常是另一种颜色

#### Scenario: 名称以表情开头
- **WHEN** 人设名以一个表情符号开头
- **THEN** 头像显示完整的表情，不出现乱码或半个字符

### Requirement: 详情名称与数值对齐

工作区右栏中以“名称—数值”成对显示的信息 MUST 位于同一行，首行顶端对齐；数值过长时 MUST 只在数值一侧换行，名称不被挤压或换行。

#### Scenario: 试聊详情对齐
- **WHEN** 管理员选中一轮试聊，右栏显示“生成与校验”
- **THEN** “模型”“耗时”“输入 token”等每一项的名称和数值首行顶端相差不超过一像素

#### Scenario: 长数值换行
- **WHEN** 一项数值是四十个字符的模型名
- **THEN** 只有数值一侧换成多行，名称保持一行且宽度不变
