# 试聊与动态对话排版改版实施任务

当前完成 8/17 项。规格见 [panel-design-system](specs/panel-design-system/spec.md)、[chat-test](specs/chat-test/spec.md)、[activity-feed](specs/activity-feed/spec.md)，实现边界见 [design.md](design.md)，选定草图见 [design-mockup.html](design-mockup.html)。

- 构建和界面测试只在服务器隔离环境 `/srv/role-workflow-proposals` 执行，用模拟接口，不使用生产 profile，不调用真实模型。
- 生产发布需要管理员另行授权；提案创建不视为任何授权。
- 实施前确认 `chat-test.js`、`feed.js`、`style.css`、`shell.js` 和相关测试文件中 `convert-trigger-cards-to-skills` 的改动状态（design.md 第 6 节）；未提交时先与管理员确认基线，不覆盖其改动。

## 1. 共用部分

- [ ] 1.1 `style.css` 新增 `--ws-fill`、六组头像变量和第 1.2 节的共用样式类（浅色、深色）。验收：六组配色在两种主题下文字对比度均不低于 4.5:1；人设模式、日程模式和设置页的截图与改动前一致。
- [x] 1.2 `shell.js` 新增 `avatar()`、`divider()`、`timeDivider()`、`reply()`、`detailRow()`，`sideItem` 的 `icon` 改用头像（第 1.3 节）。验收：`workspace-shell-ui-acceptance` 覆盖同一种子同色、表情开头完整显示、空名称显示“?”；`timeDivider()` 覆盖首条、两分钟、八分钟、跨日；`reply()` 的点击、Enter、空格选中，以及按钮内点击不触发选中；现有 `turn()`、`composer()`、`sideItem()` 调用的输出不变。
- [x] 1.3 摘要显隐与选中样式（第 1.2 节 `.ws-stat`、`.ws-reply.selected`）。验收：悬停、键盘聚焦、选中时摘要 `opacity` 为 1，移开为 0；模拟 `hover:none` 时只在选中后显示；`detailRow` 名称与数值顶端相差不超过 1px，四十字符数值只在数值列换行。

## 2. 试聊对话区

- [ ] 2.1 时间与渠道分隔、用户消息标记（第 2.1 节）。验收：夹具覆盖首条、同渠道两分钟、同渠道八分钟、跨日、公开切私信、私信切公开六种情况；已完成轮次的消息下没有“待处理”，失败轮次和未处理排队消息有，`context`／`merged` 显示“作为上文”／“合并处理”。
- [x] 2.2 回复块：头像、名称行、卡片标签、正文、结果提示、处理中（第 2.1 节）。验收：夹具覆盖回复成功、读取两张卡、读取四张卡、跳过、过滤、冷却、超长不发出、可能提及私信、格式标记、失败、取消、处理中、已删除人设，逐项断言显示内容；对话中不出现模型名和 token 数。
- [x] 2.3 操作行：详情、复制、重试与选中联动（第 2.1 节）。验收：复制成功与被拒两种情况各有提示；“重试（会再次计费）”只在失败、取消轮次出现；点击“详情”后只有该轮回复带浅色底；860px 以下右栏以浮层打开，Esc 关闭后焦点回到该按钮。

## 3. 试聊输入区与右栏

- [x] 3.1 圆角输入框、自动长高、底部控件行与说明行（第 2.2 节）。验收：二十行文字后输入框高度不超过 220px，`resize` 为 `none`；Shift 加回车换行、回车发送、输入法组字时回车不发送；人设胶囊 `inputValue()` 与选择一致；渠道单选切换后发出的消息渠道正确；`#chat-test-hold` 可用 `check()` 开启；所有控件有可读名称。
- [x] 3.2 让角色回复与停止按钮（第 2.2 节）。验收：开启先攒几条后连发两条私信，出现“让角色回复 · 2 条”，公开为“回复下一条”；处理中 `#chat-test-send` 隐藏、`#chat-test-cancel` 可见，点击后本轮取消、消息回到待处理、发送按钮恢复。
- [ ] 3.3 试聊右栏改用共用 `detailRow()`（第 2.3 节）。验收：“人设与分级”“生成与校验”“关联调用”中每一行名称与数值顶端相差不超过 1px。

## 4. 动态

- [ ] 4.1 主区对方消息与时间分隔（第 3.1 节）。验收：对方气泡上下没有渠道、分级和时间，悬停后摘要显示分级、分级原因和时间；时间不可靠时摘要写“采集时间”；按天分隔改为五分钟或跨日分隔；过滤、合并、冷却的气泡下有对应标记。
- [x] 4.2 角色一侧：头像、名称、状态、原因、操作行（第 3.1 节）。验收：夹具覆盖已发送、草稿、等待处理（回复时段关闭）、等待发送、发送中、待回查、发送失败、已跳过、已过滤、合并、冷却、角色帖已错过、无人设记录，逐项断言状态样式、原因文字、出现的操作按钮和链接；`confirmed` 状态无底色；无人设记录时显示账号 handle。
- [ ] 4.3 草稿圆角框（第 3.1 节）。验收：框内有“重写”（带计费标记）与“发送”；十行草稿时框长高且无拖拽角；改字后点击发送，批准请求携带修改后的文字和原修订号；`expired` 时禁用；后台状态变化时保留编辑并显示原有提示；实时刷新时输入焦点和光标不丢失。
- [ ] 4.4 左栏头像与状态文字、右栏改用 `detailRow()`（第 3.2、3.3 节）。验收：左栏头像在两种主题下文字对比度达标，公开、私信、角色帖三种头像文字正确，未读徽标位置不变；状态按需要处理与否显示不同颜色；右栏内容和顺序与改动前一致，成对信息顶端对齐。
