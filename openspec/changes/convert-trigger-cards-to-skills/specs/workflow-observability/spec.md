# 主程序可观测性增量规格（触发卡按需读取）

## MODIFIED Requirements

### Requirement: 实时阶段与关联信息

系统 MUST 展示等待、身份检查、公开／私信采集、排队、上下文、记忆召回、生成、发送、回查、整理、退避及错误阶段，包含开始时间、持续时间、轮次和可用关联 ID。生成阶段 MUST 覆盖一条回复的全部生成请求，结束时显示请求轮数和读取的触发卡数量；不再有单独的语义判定阶段，历史记录中的语义判定阶段照常显示。

#### Scenario: 一条消息进入语义判定
- **WHEN** 工作流为一条消息生成回复，期间读取了一张触发卡（原来的语义判定已并入生成）
- **THEN** 设置页“排查问题”区显示一个生成阶段，耗时包含两轮请求，并显示请求 2 轮、读取卡片 1 张及该消息的关联信息

#### Scenario: 查看升级前的记录
- **WHEN** 管理员查看升级前一条经过语义判定的消息
- **THEN** 原有的语义判定阶段和耗时照常显示
