# 人设库增量规格（人设文件第 2 版）

## MODIFIED Requirements

### Requirement: 本地人设文件往返

管理员 MUST 能导出已保存人设为本地 JSON 文件，并选择文件导入为一个新的人设。导出文件 MUST 使用第 2 版格式，包含格式、版本、名称和完整分区及触发卡，不得包含记忆、聊天、凭据或内部身份。导入 MUST 接受第 1 版和第 2 版文件：第 1 版文件中的关键词卡和标题含“被问到才用”的分区按旧人设升级规则转换后再校验。导入 MUST 校验格式版本、内容、名称唯一和二十项上限，失败不得部分写入；成功 MUST 生成新身份并保持原使用中人设和运行控制。编辑未保存时 MUST 提示先保存再导出。

#### Scenario: 下载和重新导入
- **WHEN** 管理员导出一个带触发卡的已保存人设，选择该文件并指定唯一名称
- **THEN** 浏览器触发第 2 版 JSON 下载，导入得到内容一致的新身份，不切换使用中

#### Scenario: 导入第 1 版文件
- **WHEN** 管理员导入一个 0.1.20 导出的、含关键词卡和“外貌（被问到才用）”分区的文件
- **THEN** 新人设中关键词卡成为普通触发卡，“外貌”成为触发卡，原内容保留；文件本身不被修改

#### Scenario: 文件损坏
- **WHEN** 选择损坏 JSON、未知版本或无效内容
- **THEN** 显示错误且原人设库保持不变
