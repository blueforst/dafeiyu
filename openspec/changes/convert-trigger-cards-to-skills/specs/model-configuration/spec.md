# 模型配置增量规格（连接测试包含工具调用）

## MODIFIED Requirements

### Requirement: 单模型测试与切换确认

模型列表中的每个模型 MUST 可单独测试，测试按钮带“计费”标记，结果（通过及耗时，或失败原因）显示在该行并保留到下次测试。测试 MUST 用该服务商的地址和 Key 发送一次带测试工具的小请求，请求结构与正式回复的工具请求相同；只有模型返回了对测试工具的调用才算通过，未调用工具或接口拒绝工具参数时显示为失败并说明原因。把最近一次测试未通过或从未测试的模型设为使用中时，系统 MUST 先请求管理员确认。

#### Scenario: 测试单个模型
- **WHEN** 管理员点击某模型的“测试”
- **THEN** 系统发送一次带测试工具的小请求，模型调用该工具后在该行显示通过及耗时，并记录到统一计费流水

#### Scenario: 接口不支持工具调用
- **WHEN** 被测接口拒绝工具参数，或模型只返回文字没有调用工具
- **THEN** 该行显示测试失败及“未完成工具调用”的原因，不显示为通过

#### Scenario: 切换到未测试的模型
- **WHEN** 管理员把从未测试的模型设为使用中
- **THEN** 页面先提示该模型未通过测试，管理员确认后才切换
