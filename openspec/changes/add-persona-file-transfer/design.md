# 人设文件传输设计

使用 `{format:"role-workflow-persona",version:1,name,persona}` JSON，排除内部 ID、修订、固定系统规则、Key、记忆、消息和模型配置。导出读取已保存内容；存在未保存编辑时提示先保存。浏览器 Blob 下载到本地，资源 URL 下载启动后释放。

`GET /api/personas/:id/export` 返回文件对象；`POST /api/personas/import` 接受 `{document,name?}`，服务器复用完整内容验证、新 ID、名称唯一和库数量检查，原子新增，使用中不变。写入口遵守共同鉴权、控制标记和同源校验。浏览器选择单个 JSON 文件，120 KB 上限；接口 128 KB 请求上限，服务端为最终校验。

以服务器接口往返、无效文件不写入、使用中保持，以及浏览器真实下载事件和文件选择验收。导入项使用既有 `blank` 来源，旧版可继续读取完整内容，无需转换或迁移。发布和试聊沿用本轮用户授权。
