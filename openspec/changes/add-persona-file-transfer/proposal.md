# 人设文件导入与导出

## Why

管理员要求把人设下载到本机保存，并选择本地文件导入，便于备份和分享人设内容。

## What Changes

人设操作菜单新增导出本地 JSON，新建菜单新增选择文件导入。导出仅包含已保存的名称、分区及触发卡；导入前显示名称，由管理员确认后新增未使用人设。沿用二十项上限、名称唯一、内容校验和原子保存，不调用模型。

## Capabilities

### Modified Capabilities

- `persona-library`：版本化文件往返。

## Impact

涉及人设库、接口和编辑器。没有数据库迁移；导入项使用既有空白来源并保留完整正文，不继承预设的可信来源。回退旧版仍可读取，不改变其他人设和控制状态。
