# 账号状态与合规检查增量规格

## Purpose

识别当前工作账号被冻结、锁定、只读或受限的状态，并定期只读检查简介披露、自动化账号标签与通知质量过滤设置，使账号异常时立即停止自动操作，资料不合规时提醒管理员处理，降低被平台判定为冒用或垃圾账号的风险。

## ADDED Requirements

### Requirement: 账号受限识别

系统 MUST 在身份检查、采集与发送结果中识别账号冻结、锁定、只读和受限状态；识别到时立即安全暂停，产生带受限类型的异常告警，不得自动恢复，也不得把它当作普通人工验证或平台拒绝重试。

#### Scenario: 页面显示账号已冻结
- **WHEN** 身份检查时页面显示账号被冻结或处于只读状态
- **THEN** 系统暂停，不再采集或发送，主页面显示受限类型与发现时间

#### Scenario: 管理员处理后恢复
- **WHEN** 管理员解除受限后手动恢复处理
- **THEN** 系统重新检查身份与受限状态，确认正常后才开始处理

### Requirement: 自动化拦截提示区分

系统 MUST 将平台“请求看起来像是自动产生”一类的拒绝提示单独记录为自动化拦截，沿用现有通道退避；同一通道二十四小时内出现三次及以上时产生异常告警并提示降低频率。

#### Scenario: 一天内多次自动化拦截
- **WHEN** 公开通道一天内第三次被识别为自动化拦截
- **THEN** 系统产生异常告警，告警说明拦截次数与当前小时、每日额度

### Requirement: 简介披露检查

系统 MUST 每天只读检查一次当前账号的名称与简介，确认包含管理员配置的全部披露词（默认“AI”，大小写不敏感）；缺少时显示注意级提示并列出缺少的词，不得自动编辑账号资料。

#### Scenario: 简介缺少披露词
- **WHEN** 当前账号简介不包含“AI”
- **THEN** 主页面账号区显示简介披露不完整，并说明需要人工修改

#### Scenario: 无法读取资料
- **WHEN** 资料页无法可靠解析
- **THEN** 检查结果显示无法确认，不判为合规

### Requirement: 自动化账号标签检查

系统 MUST 在每日检查中识别当前账号资料是否显示自动化账号标签，结果为已标注、未标注或无法确认；未标注时显示注意级提示与人工设置说明，不得自动修改账号设置。

#### Scenario: 未标注自动化账号
- **WHEN** 资料页没有自动化账号标签
- **THEN** 系统显示未标注提示，不影响正常处理

### Requirement: 通知质量过滤检查

系统 MUST 在每日检查中读取通知设置的质量过滤状态；开启时显示注意级提示，说明可能有部分提及收不到；无法读取时显示无法确认，不得自动修改设置。

#### Scenario: 质量过滤开启
- **WHEN** 通知设置显示质量过滤已开启
- **THEN** 主页面显示该提示与检查时间

### Requirement: 合规检查不干扰业务

合规检查 MUST 通过与回复、私信、定时帖子共用的浏览器互斥执行，只在两次业务操作之间进行；人工接管期间不执行，暂停期间只在管理员手动发起时执行；检查不得点击发送、修改资料或设置。

#### Scenario: 人工接管期间到达检查时间
- **WHEN** 每日检查到期时系统处于人工接管
- **THEN** 检查推迟到接管释放并恢复后执行

#### Scenario: 暂停时手动检查
- **WHEN** 管理员在暂停状态点击立即检查
- **THEN** 系统只读取资料与设置页面并更新结果，保持暂停
