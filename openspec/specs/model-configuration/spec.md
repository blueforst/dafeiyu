# 模型配置

## Purpose

记录已交付的模型服务商选择、协议适配、密钥管理和连接测试能力，使本轮新增统一计量与多种 LLM 用途时仍保留现有模型兼容性。当前能力包含 Pi 内置服务商目录和 CommandCode 预设，不等同于所有服务商均已实测可用。

## Requirements

### Requirement: 服务商与模型配置

系统 MUST 展示已接入和暂未接入的服务商及原因，允许管理员配置可用模型或自定义兼容接口，并在后续处理轮次使用保存的配置。

#### Scenario: 服务商暂未接入
- **WHEN** 某服务商需要尚未支持的认证或云参数
- **THEN** 页面展示原因且不允许误选为已可用服务商

#### Scenario: 保存新模型
- **WHEN** 管理员保存有效配置
- **THEN** 后续处理使用新配置，无需重建镜像且不会自动恢复暂停的业务

### Requirement: 密钥与模型兼容性

系统 MUST 只在服务器请求所选模型时使用对应密钥，界面与常规日志只显示掩码；模型测试和正式请求必须保留已接入服务商要求的协议、地址、认证与会话兼容行为。

#### Scenario: 读取保存的模型
- **WHEN** 管理员读取模型配置或日志
- **THEN** 响应不包含完整密钥

#### Scenario: 服务商要求稳定会话
- **WHEN** 已接入服务商的正式会话继续生成回复
- **THEN** 请求保留该服务商要求的会话路由信息，不退回不兼容的无会话请求

### Requirement: 请求额度与未知价格

新建正式回复配置 MUST 默认使用 4096 token 输出上限并受模型及现有范围约束；连接测试必须采用较小请求。CommandCode 缺少价格时不得显示为免费。

#### Scenario: 新建模型配置
- **WHEN** 管理员创建模型设置
- **THEN** 默认正式回复上限为 4096 token，连接测试不按此上限请求长篇输出

#### Scenario: CommandCode 没有价格
- **WHEN** 页面展示没有可靠价格的 CommandCode 模型
- **THEN** 页面标记价格未提供而不套用原厂价格
